### Provider 查询 chip 条功能与故事

画廊（以及画册右栏）的第二行是一排常驻的查询 chip，不需要先点「筛选」总开关。每个 chip 是一个白底粉紫描边的圆角小方块图标按钮，对应一个查询维度：排序、顺序（正序 / 倒序），细竖分隔线后是搜索（放大镜）、时间（日历）、插件（拼图）、媒体种类（图片框）、比例（屏幕框）、尺寸（叠层），末尾是文字胶囊「A 高级 ▾」，条的最右端有一个「…」按钮用来勾选哪些 chip 显示在条上（关掉的维度仍可在「高级」里用）。

点击某个 chip，会在它正下方弹出一个轻量 popover，里面是该维度的 Provider 过滤选项（例如时间维度展示「今日 / 本周 / 本月」，插件维度展示「Pixiv / Konachan / …」）。选中后该 chip 变为高亮描边，画廊实时刷新；多个 chip 可以同时生效，条件叠加。

搜索 chip 的 popover 结构固定：第一行是关键词输入框（提示「输入关键词，多个用英文逗号分隔」）和右侧的「全选」勾选框；下面是小标题「搜索范围」和两列共六个勾选项：显示名称、本地路径、链接、元数据、原生元数据、标签，每项后面跟一个小问号；最底下是一两行灰色说明文字。

漫画里可以把 chip 条画成一排小小的「维度门牌」，每个门牌代表一个维度；点开某个门牌时，下方弹出一个可爱的小弹窗，里面是该维度的发光选项节点或勾选项。看板娘像分类管理员一样依次点开各个门牌，小乌龟壳背包精灵如果化为助手，可以举着对应维度的路牌。故事感是「查询不是打开一棵大树，而是一排小门，每扇门后各有一片天地」。

Provider 查询条视觉约束：

查询条是工具栏里的一排图标小方块，不是一棵展开的大树从页面中间弹出来，也不是带文字的长按钮行。popover 半透明白底、小而精，贴在 chip 下方，里面文字尽量短，最多保留「全部、今日、本周、Pixiv、PNG、横屏、显示名称、标签」等关键词。生效的 chip 带高亮描边。如果图片模型容易乱写字，可以只画 chip 图标和勾选框轮廓，后期再补文字。整体感是「一排维度小门 + 轻量 popover」，不是「一个展开的大型筛选面板」。

图片网格具体元素：

网格卡片显示二次元壁纸缩略图。卡片角落没有任何小标签，最多是视频缩略图的右上角有一个播放按钮。选中图片时卡片边框变成粉红色。
