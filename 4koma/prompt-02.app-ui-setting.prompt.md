## Kabegame 应用

Kabegame 是一个基于 Tauri 的二次元壁纸爬取、管理、设置和轮播客户端。它可以通过插件从 Pixiv、Konachan、anime-pictures 等二次元壁纸站点收集图片，也可以导入本地图片、视频、文件夹或 .kgpg 插件。用户在应用里整理画廊、创建画册、预览图片、设置桌面壁纸、开启自动轮播，还可以管理爬虫任务和插件。

应用气质：

“二次元人自己的开源壁纸工具”。温柔、轻快、实用，像一只安静的小龟守护桌面壁纸收藏。画面应表现为现代桌面壁纸管理器，不是聊天软件、浏览器首页、普通文件管理器或游戏战斗界面。

角色与界面的关系：

Kabegame 看板娘不是站在空背景里，她应该像应用里的小管理员：在画廊缩略图之间整理图片，在插件页面给插件分配小房间，在左侧导航前带路，在任务抽屉旁查看进度。小乌龟壳背包精灵可以在背包形态和小乌龟助手形态之间切换，拿着路径树、筛选器、扳手、放大镜、播放按钮或相册标签；同一画面不要同时出现背包形态和独立小乌龟形态。

通用视觉约束：

应用 UI 元素应该简化成可读的漫画背景，不要画成真实软件截图，也不要塞满无法识别的小字。左侧导航、顶部工具栏、图片网格、画册卡片、插件卡片这些结构要清楚。文字可以只保留短标签，例如“画廊”“画册”“插件”“设置”“尺寸”“格式”“名称”“4.1.1”“4.1.0”。
