表的两个使用方

使用方怎么用表过时、取不到时
① 编译 SceneFs表里没有的位置不探；表里的按真实写法读（不分 ASCII 大小写，Linux / macOS 上大小写不同的文件也读得到）；目录写法对不上的根照旧探表里有但读不到 → 接着找下一处；三处表里都没有 → 按原写法补探一次；没有表 → 照旧逐个探。结果不受表影响，只是多探几次
③ 脚本 __workshopId 改写三处的键并成一个集合，路径在里面就不改写脚本是同步的、不能补探：表过时以表为准，要重启应用才看得到运行中新增的文件；取不到表 → 空集，全部改写

改动前的实测（2026-11-27）

场景探工程散文件不同路径原因
383759841444 次22render_scene 的屏外宿主加载一次，探针再编译一次（产品里一次）
383672562554 次27同上
3643916956602 次249会话开好后 clearCaches() 连「没找到」也清掉，18 次单对象重编译各探一遍

当时每次探不到都记一行 info 级 deny file … NotFound（799 行全是这种），资源随后在 pkg 或 assets 命中，画面没问题，但曾被误读成「依赖条目没下载」。
