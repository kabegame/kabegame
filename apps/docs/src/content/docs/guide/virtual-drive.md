:::caution[此功能已于 v4.7.0 下线]
「虚拟盘（VD，又称画册盘）」曾把图库挂载成系统里的一个磁盘或目录。从 v4.7.0 起，这项功能已被彻底移除，设置、顶栏和画册菜单里不再有对应入口。
:::

## 为什么下线

1. **图库本身已经够用。** 图库的浏览、筛选、排序与画册组织已经能覆盖日常需求，不再需要把图库挂成一个盘、再用资源管理器去翻目录。
2. **有更强的替代方式。** 想在应用之外按条件找图、取图，可以在「设置 → 高级」里开启 Web 服务器，它提供的**画廊查询**比文件系统的目录视图表达力强得多。
3. **维护成本与收益不成比例。** 虚拟盘需要安装 Dokan、macFUSE 或 FUSE 这类系统级驱动，带来的安装与分发负担，与它只能提供只读目录视图的能力不相称。

## 你需要做什么

- 升级后不需要任何操作，图库与画册里的图片都不受影响。
- 如果你之前专为 Kabegame 安装过 Dokan（Windows）或 macFUSE（macOS），现在可以自行卸载，Kabegame 不再需要它们。
