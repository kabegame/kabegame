`@kabegame/plugin-sdk` 是一个**打包进插件产物**的 npm 工具库，提供 URL 解析、正则、md5、类型声明等纯工具，以及少数把几步宿主调用包在一起的辅助函数（如 `downloadWpeWallpaper`）。

:::caution[和 `Kabegame.*` 不是一回事]
本页的 SDK 与运行时注入的宿主全局 `Kabegame.*` 是**两种完全不同的东西**：

| | `@kabegame/plugin-sdk` | `Kabegame.*` |
|---|---|---|
| 来源 | 你 `import`，**打包进**你的 `dist/main.js` | **运行时注入**的全局对象，不 import |
| 内容 | 纯 JS 工具函数 + TS 类型 | 宿主能力（导航、下载、DB、fs…） |
| 能否离线跑 | 大多可以（纯计算） | 不行，需要宿主 |

宿主能力见 [V8 脚本](/dev/v8-api/) 与 [Kabegame API 字典](/reference/kabegame-api/)。
:::

SDK 主要服务 V8 后端（用 TypeScript 写在 `src/`，打包成单个 `dist/main.js`）。WebView 后端有真实浏览器环境，通常直接用原生 API，用到的 SDK 较少。

## 安装与使用

```bash
npm i -D @kabegame/plugin-sdk @kabegame/types
```

`kabegame-cli plugin new` 生成的 V8 模板已经带上这两个依赖。SDK 以 MIT 许可发布。

在插件源码里直接 import，打包器会把用到的部分内联进产物：

```ts
import { type kbCrawlFn, resolveUrl, sleep } from "@kabegame/plugin-sdk";

export const crawl = (async (common, custom) => {
  await Kabegame.to("https://example.test/posts");
  await sleep(1000);
  await Kabegame.downloadImage(await resolveUrl("/image.jpg"));
}) satisfies kbCrawlFn;
```

## URL

### `resolveUrl`

两个重载：

```ts
resolveUrl(relative: string, base: string): string             // 同步，相对显式 base 解析
resolveUrl(relative: string): Promise<string>                  // 异步，相对 Kabegame.currentUrl() 解析
```

- 给了 `base` → 同步返回 `new URL(relative, base).toString()`。
- 不给 `base` → 异步，相对**当前页面 URL**解析（内部读 `Kabegame.currentUrl()`）；当前 URL 不可用时原样返回 `relative`。

```ts
const a = resolveUrl("/images/o.jpg", "https://example.test/post/1");  // 同步
const b = await resolveUrl(href);                                       // 相对当前页
```

:::note
不带 base 的异步重载依赖宿主 `Kabegame.currentUrl()`，因此它不是"纯"工具——但它仍是打包进插件的代码，不是宿主注入的方法。
:::

## 时间与延时（misc）

```ts
unixTimeMs(): number                            // = Date.now()
randF64(min = 0, max = 1): number               // [min, max) 随机浮点
sleep(ms: number): Promise<void>                // 至少等待 ms（用 Web timer，无需 Node API）
```

```ts
await sleep(randF64(500, 1500));  // 随机退避
```

## 正则（regex）

不抛异常的正则工具，适合处理来自插件配置的模式串（非法模式返回安全默认值而非报错）：

```ts
reIsMatch(pattern: string | RegExp, text: string): boolean
reReplaceAll(pattern: string | RegExp, replacement: string, text: string): string
reFindAll(pattern: string | RegExp, text: string): KbRegexMatch[]
```

`reFindAll` 返回的每个 `KbRegexMatch`：

```ts
interface KbRegexMatch {
  match: string;                       // 完整匹配文本
  captures: string[];                  // 位置捕获组（缺失归一化为空串）
  groups: Record<string, string>;      // 命名捕获组
  index: number;                       // 匹配在文本中的 0 基下标
}
```

md5(value: string): string            // 十六进制 md5，用于构造去重 key、签名参数等

## Wallpaper Engine 壁纸（wpe）

<Badge text="4.7.0" variant="note" /> Wallpaper Engine 的一张壁纸是一个文件夹（`project.json` 加上视频、网页或场景文件），在 Kabegame 里是一条记录。`downloadWpeWallpaper` 按文件清单把这个文件夹逐个文件下到任务的虚拟文件系统，再用 `Kabegame.downloadImage(目录, { relocate: true })` 整个提交：应用把文件夹移进输出目录，库里已有同一张壁纸时直接删掉刚下载的这份。仅桌面端，V8 与 WebView 后端都能用。

```ts
downloadWpeWallpaper(opts: DownloadWpeWallpaperOptions): Promise<void>
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `rootUrl` | `string` | 壁纸目录的地址。每个文件从 `rootUrl + "/" + 相对路径` 下载，路径各段会经过 `encodeURIComponent`。 |
| `files` | `{ path: string; size?: number \| null }[]` | 要下载的文件，`path` 是相对壁纸目录的路径，用 `/` 分隔。必须包含 `project.json`。 |
| `name` | `string \| null` | 展示名，也是落盘的文件夹名。不传时用 `project.json` 里的标题。 |
| `workDir` | `string` | 下载用的虚拟目录，默认 `${Kabegame.fs.getRoot()}/tmp/wpe`。 |
| `headers` | `Record<string, string>` | 每个文件请求附带的请求头。 |
| `retries` | `number` | 单个文件失败后的重试次数，默认 2。 |
| `onFileDone` | `(file, index, total) => void` | 每个文件下载成功后调用，通常用来打日志。 |
| `downloadOptions` | `{ url?, labels? }` | 帖子地址与标签，含义同 `downloadImage` 的同名选项。不能传 metadata：应用把壁纸自己的 `project.json` 存成它的 metadata。 |
| `dryRun` | `boolean` | 传入 `common.isDryRun`。为 `true` 时不下载任何文件，只让应用记一次空跑。 |

```ts
import { downloadWpeWallpaper, type kbCrawlFn } from "@kabegame/plugin-sdk";

export const crawl = (async (common) => {
  const rootUrl = "https://example.test/wallpapers/1234";
  const listing = (await (await fetch(rootUrl)).json()) as {
    files: { path: string; size?: number }[];
  };

  await downloadWpeWallpaper({
    rootUrl,
    files: listing.files,
    name: "My wallpaper",
    dryRun: common.isDryRun,
    downloadOptions: { url: "https://example.test/post/1234" },
    onFileDone: (file, index, total) => console.log(`${index + 1}/${total} ${file.path}`),
  });
}) satisfies kbCrawlFn;
```

- 相对路径里带 `..`、以 `/` 开头、含反斜杠或盘符时直接报错。
- 一个文件要响应状态为 200、且（给了 `size` 时）大小一致才算成功，否则重试；重试用完后抛错。
- 函数返回时文件夹已经交给应用的下载队列，由应用移走，成功时 `workDir` 里不留东西。中途抛错会删掉没下完的文件夹；被强行中断留下的残留，在 12 小时后的下一次调用时清理。
- 文件是依次下载的，不占应用下载队列的并发名额。一次传多张大壁纸时，建议在插件里自己排队，一张一张来。

## TypeScript 类型

SDK 还导出用于给 `crawl` 加类型的辅助（纯类型，无运行时开销）：

| 类型 | 说明 |
|---|---|
| `kbCrawlFn<CustomCfg>` | `crawl` 入口的签名：`(common: KbCommonCfg, custom: CustomCfg) => void \| Promise<void>`。 |
| `KbCommonCfg` | `common` 的形状：`{ baseUrl: string \| null; isDryRun: boolean }`。 |
| `kbCustomCfg<Fields>` | 由字段列表构建 `custom` 的类型。 |
| `kbCfgField<K, T, M>` | 描述一个 `custom` 字段。第三个泛型可用 `{ required: true }` 去掉 `null`，或用 `{ when: true }` 把 key 标为可选。 |
| `kbCfgInt` / `kbCfgStr` / `kbCfgBool` / `kbCfgDate` / `kbCfgList<T>` / `kbCfgOption<T>` / `kbCfgCheckbox` | 各 `kbConfig` 变量类型对应的值类型。 |
| `JsonValue` / `JsonObject` / `JsonPrimitive` | 可跨宿主边界的 JSON 值。 |

给 `custom` 加类型：

```ts
import type { kbCfgField, kbCfgInt, kbCfgStr, kbCustomCfg, KbCommonCfg } from "@kabegame/plugin-sdk";

type Cfg = kbCustomCfg<[
  kbCfgField<"startPage", kbCfgInt, { required: true }>,
  kbCfgField<"tag", kbCfgStr>,
  kbCfgField<"artistId", kbCfgStr, { required: true; when: true }>,
]>;

export async function crawl(common: KbCommonCfg, custom: Cfg) {
  const startPage = custom.startPage;       // required：number，不含 null
  const tag = custom.tag ?? "";             // 普通字段：string | null
  const artistId = custom.artistId;         // when：字段可能不存在
}
```

boolean 字段即使没有 `required` 也不会包含 `null`；`kbCfgCheckbox<"desktop" | "mobile">` 表示完整的 `{ desktop: boolean; mobile: boolean }` 对象。`when` 字段在隐藏时整个 key 缺失，因此代码应使用可选访问或先判断 key 是否存在。

:::note
`Kabegame` 全局的类型声明在单独的 `@kabegame/types`（`packages/kabegame-types/lib.kabegame.d.ts`），把它加入插件的 `tsconfig` 即可获得 `Kabegame.*` 的类型提示。它只覆盖 V8 后端的完整 API。
:::
