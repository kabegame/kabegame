# V8 插件参考

权威来源：宿主 API 类型 `packages/kabegame-types/lib.kabegame.d.ts`（带示例）、运行时说明
`cocs/crawler/V8_RUNTIME.md`、包格式 `docs/PLUGIN_FORMAT.md`。这里只放写插件最常用的部分。

## 目录与 package.json

照抄 `plugins/wallspic` 的结构：`src/index.ts` 用 rspack 打成自包含 ES module `dist/main.js`。

```jsonc
{
  "name": "my-site",                 // = 插件 id = 目录名，[a-zA-Z0-9_-]，≤64 字节
  "version": "0.1.0",
  "private": true,
  "name.zh": "…", "name.en": "…",   // 展示名，按 locale 后缀
  "description": "…",
  "author": "Kabegame",
  "kbPackageVersion": 3,
  "engines": { "kabegame": ">=4.3.0" },
  "main": "dist/main.js",
  "kbBackend": "v8",
  "scripts": { "build": "rspack build" },
  "kbBaseUrl": "https://site.example",   // 运行时以 common.base_url 传入
  "kbIcon": "icon.png",
  "kbDoc": { "default": "README.md" },
  "kbConfig": [ /* 见下 */ ],
  "devDependencies": { /* 照抄 wallspic */ }
}
```

`kbLabels`（插件徽标，只有 6 个合法 id）与 `kbConfig`（8 种变量类型及 `when` / `width`）的完整说明见
[manifest.md](manifest.md)。

```ts
export async function crawl(common, custom) {

  const vars = custom || {};          // kbConfig 合并后的值，键 = kbConfig.key
  // …

```

- 模块必须自包含：运行时 `module_loader = None`，所以运行时的 `import` 一律失败。依赖靠 rspack
  在构建时打进 bundle（`@kabegame/plugin-sdk` 的 `resolveUrl` 等纯工具可以用）。
- `console.log` 会进任务日志（级别 print）；`Kabegame.warn` 是 warn 级别。

## 常用宿主 API

| API | 用途 |
|---|---|
| `await Kabegame.to(url)` → finalUrl | 抓页面并压入 page stack（带任务请求头、重试、跟随重定向） |
| `await Kabegame.currentHtml()` / `currentDocument()` / `currentUrl()` | 读当前页 |
| `await Kabegame.back(n?)` | 弹出 page stack |
| `fetch(url, init)` | 标准 fetch（宿主 reqwest 实现）；取 JSON 用它。**相对 URL 不会自动解析** |
| `new DOMParser().parseFromString(html, "text/html")` | deno-dom，与 `probe.ts sel` 同一实现 |
| `Kabegame.setHeader(k, v)` / `delHeader(k)` | 任务级请求头，`to` 和 `fetch` 都会合并 |
| `Kabegame.requireCookie(host?)` → boolean | 注入用户在畅游里登录后留下的 Cookie |
| `Kabegame.cefUserAgent()` | 畅游的 UA；Cloudflare 的 `cf_clearance` 绑定 UA，注入 Cookie 时一起设 |
| `Kabegame.createImageMetadata(obj)` → id | 一个作品建一行 metadata，多张图共用 |
| `await Kabegame.downloadImage(url, { name, url: 作品页, metadata_id, labels })` | 入队下载（URL 和 hash 双重去重） |
| `Kabegame.addProgress(pct)` | 累加进度，总和约 100 |
| `Kabegame.pluginData()` / `setPluginData(obj)` | 插件私有持久 JSON（游标、token 缓存） |
| `Kabegame.fs` / `Kabegame.archive` / `Kabegame.ffmpeg` | 任务私有 VFS、解压、合流（见 d.ts） |

## 典型骨架（列表 → 详情 → 下载）

```ts
function parse(html) {
  return new DOMParser().parseFromString(html, "text/html");
}

async function open(url) {
  const finalUrl = await to(url);
  return { finalUrl, doc: parse(await currentHtml()) };
}

export async function crawl(common, custom) {
  const base = common?.base_url || "https://site.example";
  const start = Number(custom.start_page ?? 1);
  const end = Number(custom.end_page ?? 1);
  const perPage = 100 / Math.max(1, end - start + 1);

  for (let page = start; page <= end; page++) {
    const { doc, finalUrl } = await open(`${base}/list?page=${page}`);
    const posts = [...doc.querySelectorAll("article .item a[href]")]   // ← 第 2 步实测的选择器
      .map((a) => new URL(a.getAttribute("href"), finalUrl).href);
    console.log(`[my-site] 第 ${page} 页：${posts.length} 个作品`);
    if (posts.length === 0) { addProgress(perPage); continue; }

    for (const [i, postUrl] of posts.entries()) {
      try {
        const { doc: d, finalUrl: pUrl } = await open(postUrl);
        const title = d.querySelector("h1")?.textContent?.trim() || "";
        const imgs = [...d.querySelectorAll("a.download")]               // ← 第 2 步实测
          .map((a) => new URL(a.getAttribute("href"), pUrl).href);
        const metadataId = Number(createImageMetadata({ schema: 1, title, url: pUrl }));
        for (const [k, img] of imgs.entries()) {
          await downloadImage(img, { name: imgs.length > 1 ? `${title}(${k + 1})` : title, url: pUrl, metadata_id: metadataId });
        }
        console.log(`[my-site]   ${i + 1}/${posts.length} ${title}：${imgs.length} 张`);
      } catch (e) {
        warn(`[my-site] 作品失败 ${postUrl}: ${e?.message ?? e}`);
      }
      addProgress(perPage / posts.length);
    }
  }
}
```

JSON API 站点把 `open` 换成 `await (await fetch(apiUrl)).json()`，其余结构不变。
需要 Referer 才能拉图时，在循环外 `Kabegame.setHeader("Referer", base + "/")`。
