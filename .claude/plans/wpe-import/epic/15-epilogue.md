# 尾声 史诗铸就

> 十一月十九日；293 座里的 292 座，和还没走完的路。

## 最后一次点名

十一月十九日，kamechan 把迎回工坊的箱庭全部请到陈列大厅，做最后一次点名。

一共 293 座：有故乡自带的，有从异次元的大集市上带回的，也有从集市库房里整箱搬来的。点名的办法，还是立国时立下的那条规矩：每一座箱庭把自己要用的本事一样一样报上来，看有没有哪一样，是工坊还认不出、还做不到的。

小乌龟举着检查表，从第一座盖章盖到最后一座。292 座报完，一样不缺；没有一座在半路睡着。

上一次点名是在傀儡卷收尾的时候，那时还有五座箱庭在门外等着。两次点名之间，文字那一卷补上了最后一门手艺：带描边、带投影、边缘柔和的字。四座箱庭因此进了门，没有一座退出去，也没有冒出一样新的「做不到」。

门外只剩一座：哈勃望远镜。它一直被记作「行囊里丢了九件行李」，光照那一卷做完之后，它还是醒不过来。最后一次点名时，路径魔女顺着丢失的行李单回到行囊里翻，发现行李其实一件不少：行李单上写的是大写的名字，箱子上贴的是小写的标签。

「工坊的门卫认字太较真了，」魔女把帽檐往上一推，「故乡的门卫，多半不计较大小写。」

这件事还得先回故乡定格取证，才能动手。最后一座箱庭，卡在一个字母的大小写上。

## 二十六天

从十月二十五日第一扇纸窗进门，到十一月十九日这次点名，一共二十六天。

这段日子里，工坊添了四百多块砖；箱庭之屋和两位通译那一侧，就占了两百多块。随行的箱庭从最初的 29 座，涨到 192 座、233 座，再到这一次的 293 座；苏醒的箱庭，从立国那天的三座，到今天的 292 座。

数字是死的，路是活的。回头看这二十六天，有三件事一直没变。

**第一，不猜。** 故乡的法则是一只不肯开口的黑匣子。探索队没有凭印象去补它：魔女一页一页解读古文书，小精灵们在故乡定格一瞬取证，再搭起只摆一件东西的试验小箱庭，一样一样地问它到底怎么画。古文书读来的结论，一再被实测推翻：星尘没有那条时间上限，光束不是方的，人偶静止的姿势不从那里来，交给咒语的东西也不按书写的顺序排。每推翻一次，工坊里的箱庭就离故乡的样子更近一分。

**第二，有据才不同。** 照故乡的法则做是常理，但不是盲从。法则自己也有裂缝：有时看错了来访者拨过的开关，有时星尘停了再唤它却不肯再放，有时补发的星尘落错了地方。这些裂缝，工坊不跟。可示波器那座箱庭的匠人，恰恰是踩着法则的一道裂缝造出它来的，那道裂缝就得照样留着，不然箱庭会塌。这条规矩后来写成一句话：法则里的裂缝，只在有箱庭靠它活着时才跟着走，否则按对的做，并记下「工坊有意与故乡不同」。

**第三，没有孤军。** 最热闹的时候，十几支小精灵探索队同时出发，各守一片箱庭。她们共用一本「本事清单」、一套兵器、一条规矩，彼此之间靠工坊里的文书传话。一队在路上发现的问题，会转给守那一卷的队伍去修；每一队收工时只交自己那几块砖，不碰别人还没砌好的墙。

## 铸就之后

点名结束，kamechan 把检查表收进龟壳背包，小乌龟打了个哈欠。史诗算是铸成了，可路还没走完。有几件事要说清楚，免得后来翻开这部纪年的人读错。

**「一样不缺」是点名时的结论。** 它说明这 292 座箱庭要的本事工坊都会，不说明每一座都和故乡分毫不差。用对照天秤一帧一帧称过的，确实对得上；还没称过的，可能还藏着细小的差别。已知的几处都记在各卷的文书里，比如流光边缘的一点颜色，单声道的声音比故乡略响一些。

**疆土还没铺满。** 认出工坊外正在放的歌、推开快捷之门，目前只在 Windows 的大地上；跟着指尖动，在 Windows 与 macOS 的大地上；Linux 的大地上，箱庭只能隔着玻璃看。工坊里留着三十一处小记号，记着这里试不了的地方，以及约好暂时不做的事。

**还欠着债。** 烟花那一类拖着长尾巴的星尘，每一刻都要费很大力气去描它的尾巴。当初带这种烟花的几座箱庭还没醒，这笔债可以缓一缓；如今它们都醒了，债也就到期了。

**随行的只是一小队。** 293 座只是这一次迎回的箱庭。异次元里还有更多匠人、更多玩法，迟早会撞见新的东西。到那时，办法还是老办法：先回故乡取证，再写工坊的规矩。

至于以后，魔女合上路径魔法书，说这二十六天留下的最有分量的东西，也许不是苏醒的箱庭本身，而是两样：一样是各卷文书里成百上千条「故乡实际是这么做的」实测记录，另一样是那些试验小箱庭，连同从故乡定格回来的证据。前一样是规矩的雏形，后一样是考卷的雏形。

「别的工坊想迎回箱庭，照着规矩、拿着考卷，自己考一考就知道了。」她说，「路径已经安排好了。」

kamechan 笑了笑，把最后一座箱庭的画像挂回陈列大厅，转身去翻那张写着大写字母的行李单。
