# 第四卷 军规

> 十一月八日至十四日，军规立于十三日；一座时钟箱庭里的字被悄悄拉长，暴露出各卷之间的缝隙，工坊立下走查的军规，又为守它锻造了三件兵器。

## 缝隙

各卷的验收，多半是在试验小箱庭里做的：里面只摆一件东西，位置写死，再用定格之镜在故乡定格一瞬取证，逐处比对。这能证明「这一卷学会的本事」和故乡一样。可匠人们造的真箱庭从不只摆一件东西：文字挂在一个父对象下面，父对象的大小连着一个旋钮，背后淌着一卷流光，时钟由咒语按此刻的时间念出来。许多卷的本事叠在一起，卷与卷之间的缝，试验小箱庭照不到。

十一月十三日，这道缝露了出来。文字那一卷的探索队刚让九座时钟箱庭苏醒，验收时拿故乡的取证比了三座：第一座分毫不差；第二座字的里头一样，边上有差，归给了背后在动的画面；第三座，彩纸纷飞的时钟那座，背后是流光、上面盖着彩纸，没法逐处比，看了两张截图就记成「排版和故乡一致」。其实字已经歪了。

是 kamechan 在陈列大厅里把它和故乡的样子并排摆着时看出来的：工坊里的字，明显被拉长了。

探索队回头补做。把这座箱庭复制一份，撤掉流光，把决定整组位置的那段咒语换成一个固定的位置，只留三层文字；**父对象的大小连线一点不动**。在一块纯色底上和故乡比，三层字横向完全一致，纵向都被拉长了约 1.4 倍。

一层层往回追，落到了父对象的大小上。卷宗里它的大小只写了一个数。故乡的法则是：一个数铺满横、竖、深三个方向；工坊只把它用在了横向，另外两个方向当成了 1。于是竖着比横着多放大了一截，正好是那 1.4 倍。

查这条法则的来历，更叫人警醒。立国那天，读字段时一个数只填了一个方向；第二卷魔女翻古文书时，「一个数铺满三个方向」已经记进笔记，还实测过；之后那本「哪一处连着哪个旋钮」的账原样继承了立国时的写法；箱庭的全局设置照法则铺满了，同一处管着的图层字段没改；十一月八日笔法里的数也铺满了，图层还是没改；星尘、文字里又各自另写过一份。**一条法则在四个地方照做，对了三个。**

为什么各卷都没抓到？试验小箱庭是自己搭的，没人会想到「一个数连三个方向」这种写法；文字那一卷比的是字本身；这种错不会让封印合上，只会静静地画歪；而真箱庭比不了的时候，大家退回了肉眼。迎回的箱庭里有三十多座用了这种写法，当时醒着的三座，恰好都是刚苏醒的时钟。修好之后，两版纯文字的复制品和故乡分毫不差。

## 军规

魔女把这桩事从头到尾排成一条路径，摊在桌上；kamechan 和小乌龟、各队的小精灵围在边上。大家商量之后，立下了一条走查的军规：

**先让工具到位：试验小箱庭要能还原一座箱庭的全部状态；再对着故乡录下的一段醒来的过程逐帧比对，做到分毫不差；有不一样的地方，要能讲清楚为什么。**

小乌龟把它抄在一块木牌上，拆成五条，挂在工坊门口。

第一，**先有兵器，再上路**。比不了就不开始；「看着差不多」不是结论。

第二，**要能把一座箱庭的一切都还原出来**。画面上的每一处，背后都有它的来由：客人调过的旋钮，此刻是第几秒、这一帧走了多久，鼠标在哪，咒语看到的时间与随机数，星尘从出生到此刻的全部经历，流光放到哪里，音乐的起伏，窗户多大，画质几档。这些都要和故乡那一帧一模一样，比较才有意义。

第三，**对着故乡的一段录像逐帧比**。录像不是一张截图，而是箱庭在故乡实实在在醒着的一段：用定格之镜一帧接一帧地取证，连同每一帧的全部来由。工坊照同样的来由一帧帧重演，每一帧整幅比对，目标是分毫不差。

第四，**每一处不同都要讲得清**。要追到具体的那一笔、具体的那个数，然后归入两类之一：有依据、决定不跟的已知差异，或者要修的错。「背景在动所以对不上」「颜色差几级」都不算讲清；讲不清，就是不通过。

第五，**用复制品排除干扰**。每一支探索队从真箱庭里挑出用到自己本事的那些，复制一份，只留和本卷有关的东西，其余撤掉或换成固定值；故乡那边录的也是同一份复制品。但被查的那样东西，它的父辈祖辈、它连着的旋钮、它的咒语与效果，一样都不许动。那天若是顺手把父对象的大小也换成固定值，错处就会被一起撤掉，再也找不到。

## 兵器之前的窘境

军规是十三日立的，兵器却从八日就开始锻造。那天 kamechan 带着小乌龟，把多日来随手做下、堆在工坊角落里的小工具清点了一遍，情形很狼狈。

**去故乡取证，要借两样互不相通的家什。** 定格取证靠一只旧匣子：用它之前，得先把故乡那扇常开着的门关上；用完只能硬生生掐断，下次故乡再开门，就弹出「上次可能崩溃了」，还得有人去点掉；同一时刻只容一支队伍用。看取证结果又靠另一样家什：非得开着一块大镜面，几支队伍同时用就互相覆盖，还会把别人正看着的那份换掉。

**差遣工坊自己，每次都从头来过。** 原有的办法每用一次，都要重新找门、重新敲门，说完话就走。看看界面够了，做验收不够：箱庭之屋，旧办法连门都进不去。于是角落里又长出两百多张小纸条，各自重新搭一遍通往工坊的桥，用完就拆。清点时小乌龟还翻出十一张纸条，收拾试验小箱庭时用的是「销毁」而不是「请出陈列大厅」，会把原件一起毁掉。

**比对的工具，走一步抄一份。** 星尘那一卷每走一步，就把上一步的整套工具抄进新抽屉，改改再用。到后来，同一个重演星尘的工具抄了六份，清点迎回箱庭的工具抄了十次，故意弄坏一处看测试能不能抓到的检查抄了十七次。抄来抄去，写死的路标和过时的老办法也跟着到处蔓延。

三件兵器，就是对着这三处窘境造的。

## 第一件：定格之镜

这是一面专门对着故乡的镜子，替大家定格一瞬取证、看清每一笔是怎么画的。

它的性子是这样定下的：要常驻，几支队伍共用；对故乡那扇常开着的门要**无声无息，不弹窗**；可以对那扇正开着的门施法；用完不必复原故乡的设置，但故乡里挂着的箱庭和匠人的作品一样不碰。起初的打算是「用完就放」，当晚改成了**常驻共享，不关不杀**：镜子挂上了就一直挂着，故乡的门也一直开着。

要做到这些，先得摸清故乡的脾气。小精灵们实测：镜子可以直接挂进一扇已经开着的故乡之门，眨眼之间，不必重开；挂上之后新开的窗都照得见，原有的桌面箱庭不受打扰；挂一次，可以反复开窗、反复取证。魔女又从古文书里读出故乡怎么记「上次有没有好好关门」：每次开门先在本子上记一笔「没关」，好好关门才划掉；被硬生生掐断，那一笔就留着，下次开门便弹出提示。所以万一要替故乡开门，先替它把那一笔划掉。还读出故乡的设置只在开门时读一次，所以要改设置，只能好好关门、改好、再开，而且只在没有别的队伍在用的时候做。

几支队伍共用一扇门，是这面镜子的心。每支队伍只开、只关自己的试验窗，窗上写着自己的名号，登记在一本全工坊共享的名册上；别人的窗、桌面上的箱庭一律不碰；队伍已经回家、窗还开着的，谁路过谁顺手关掉，免得它在后台白白地画。

取证本身是独占的：同一时刻只能一个人对着镜子，抢着用就会把别人挤掉。于是定下**一把共享的取证锁**，谁取证谁拿锁，只拿那么几秒；取完证慢慢端详就不在锁里了，大家可以同时看。还有一个难处：镜子一次只照「当前那扇窗」，而这扇窗是大家共用的。办法是按大小认窗：只有自己一扇就直接照；不止一扇，就先照一下看看大小对不对，不对就换一扇再看。为了认得准，规定同一时刻不许有两扇大小几乎一样的试验窗。

端详取证结果的那一半，也改成每支队伍自己在后台悄悄看，不开大镜面。从此几支队伍各看各的，也不会换掉别人正看着的那份。

中途还有一个插曲。试验窗开几秒后会跳到最前面，小精灵们一度安排了守卫把它按回去。后来商量定了：试验窗在前面可以接受，不能跳出来的是故乡自己的大厅和各种提示。守卫随之撤掉。

十一月十四日，为了「言与声与触」那一卷，镜子又学会一样本事：不碰真的鼠标，只在自己那扇试验窗里，一帧一帧地告诉故乡「此刻鼠标在这里、左键按着」；还能反过来把来访者在窗上的操作录下来，故乡和工坊的重演都照这一份走。

## 第二件：传令海螺

这是替大家差遣工坊自己的传令海螺：截一张画，递一道令，让某座箱庭画出指定的一帧，比两幅画面是否相同，把试验小箱庭请进陈列大厅再请出去。

它的结构是这样搭的：工坊里本就一直醒着的那位门房，常驻一条通往工坊各处的线，所有状态都存在他那里，谁都能直接去问；海螺另做成一只小小的，随身带着就能吹；吹之前先问门房在不在，再问线通不通；旧办法里那套笨重的家什一律卸掉。

线常驻之后，那两百多张纸条反复搭桥的事就省了；画几十遍、等搬运完成这类费时的活，交给门房慢慢做，先回一个号码牌，回头再来取。卸掉旧家什，三个老毛病一起没了：进不去箱庭之屋，被别的窗拖慢，悄悄改了工坊收东西的规矩。还立了两条安全规矩：试验小箱庭只许「请出陈列大厅」，绝不「销毁」，有一座来路不对就整批拒绝；只认最新的箱庭之屋，因为第二卷吃过亏，旧屋子还守着旧规矩，调律室里改了画质却被悄悄忽略。

此后它一回回长出新本事：把主窗口唤到前面，打开某幅画的预览；照着故乡的节奏重演星尘、读出每一颗的轨迹；按指定的大小画出一帧；给帧号块涂上那一帧该有的颜色；到十一月十四日，重演时也照样念起咒语。

## 第三件：对照天秤

这是摆在定格之镜和传令海螺之间的一架天秤：一边托盘放故乡的取证，一边放工坊的重演，逐项称。

它的样子是这样定的：一个入口，许多小命令；读取证结果时不开大镜面，直接借用定格之镜的本事；角落里那些旧纸条不去动它，照旧能用，往后的新步骤都改用天秤。

它按事情的先后分成五格：**搭场**，造出只摆一件东西的试验小箱庭；**取证**，从故乡的定格里读出星尘的轨迹、整幅画面和种种统计；**重演**，照故乡的节奏把工坊的算法重跑一遍；**称量**，逐颗、整幅、按统计地比；**守成**，把登记过的重演当成一整套回归，在改动前后各跑一遍逐字比较，再故意弄坏一处看能不能被抓到。那抄了六份、十次、十七次的工具，从此各自收成一条命令。

它还是试验小箱庭里那套暗号的主人。每座试验小箱庭的角落固定摆两块小方块：一块是帧号块，每帧把「这是第几帧」写进自己的颜色，取证时一看颜色就知道是哪一帧；一块是时钟块，让时间真正参与作画，否则取证里读到的时间是一堆没有意义的残渣。帧号块还每帧把「这一帧走了多久」记进故乡的日记，工坊重演时照这本日记走。

匠人造的真箱庭没有这些暗号。十一月十二日，探索队学会了给真箱庭「拆箱加暗号」：把它复制一份、拆开，在画面之外悄悄放一块只记日记的帧号块，不改动画面上的一个点，也不打乱咒语找东西的次序。拿海蓝那座一试，只凭日记重演，与故乡的同一帧并排，各处的错位都不到十分之一个像素。

## 军规逼出来的补丁

军规立下的第二天，各支探索队照着去走查，立刻撞出几处兵器的缺口。

**逐笔的账。** 军规要求每一处不同都追到具体的一笔。故乡那边，定格之镜能看清每一笔的位置、颜色、用了哪些数；工坊这边只有最后那幅画。一座时钟箱庭的走查就卡在这里：还差十几个点，故乡那一笔的来历全拿到了，工坊这边却拿不出对应的数。商量后定下做法：给画坊身边安一个书记，画坊照常落笔，书记只把每一笔记下来，画法一个字不改。从此工坊也有了逐笔的账，可以和故乡一笔一笔地对。

**精确的时辰，每帧都真画。** 时轮那一卷照军规走查时又撞出两处。一是日记里「这一帧走了多久」只记到小数点后六位，故乡逐帧累加出来的数，工坊重建时差了最后一位；于是日记改成原样照录。二是重演只真画最后读出的那一帧，可有一种效果读的是另一处上一帧留下的画面，在工坊这边还是一片空白；于是重演时每一帧都真画一遍。补上之后重录，动画写进去的每个数都与故乡分毫不差。

**复制品与成批比对。** 复制真箱庭原来每次都要手写一张小纸条。十一月十四日有了通用的做法：指明要留哪几样，它们的父辈祖辈、依赖的东西、咒语要找的东西自动一起留下，其余撤掉，指定的地方可换成固定值，故乡和工坊用同一份。又有了把一整段录像成批重演、逐帧比对、汇成一张总账的办法。

## 尚未齐备

军规写上木牌时，魔女也老实列出了兵器还缺什么：咒语每帧看到的「此刻」，工坊只能给一个起点往后推，故乡却是每次都看真钟；日记每十帧才写一回，有些帧拿不到当时的记录；咒语听到的音乐还是一片寂静；能自动找出「工坊和故乡从哪一笔开始不同」的称量，也还没有做。这些缺口挂在木牌下面，各卷走到时再补。

从此「看着差不多」不再是结论。往后每一卷的验收，都要先问一句：兵器到位了吗？
