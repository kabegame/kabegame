# 序章 网页之役

> 2026-10-25 至 11-01；工坊先迎来异次元的流光画卷，再把会动的纸窗箱庭连同它们故乡的规矩整个请进门，途中堵上一道藏在时差里的暗门。

## 渡口：一座箱庭是一只行囊

十月二十五日，远征从工坊最近的渡口出发。

异次元漂来的东西，从来不是一张图、一段影像那么简单。每一件都是一只行囊：里面有一份清单，写着它是什么、从哪扇门进、哪张图是它的画像、造箱庭的匠人留了哪些旋钮可调；其余的素材，都和清单装在一起。

「先说好收纳的规矩。」kamechan 把第一只行囊放上陈列大厅的长桌，「一只行囊记成大厅里的一格，这一格直接指着它原本的样子。不拆、不改装、不往里面写一个字。」

小乌龟在旁边举起检查表，一项项盖章：不复制，不转制，不留副本。行囊在异次元那头更新了、被收回了，变的只是那一只，工坊这边不藏私货。

规矩一立，麻烦也跟着来了。工坊里许多老机关向来默认「一格就是一张画」：算指纹、拖出窗外、挂进虚拟的抽屉、贴到桌面、清理源头。如今一格指着的是整只行囊，每一处机关都得先看清来者是谁，再分路走。PathQL 魔女翻工坊自己的旧图纸时，发现一处险地：大厅里删掉一格时，机关会顺手把它的小样一并扔掉，从不问那张小样归谁。而这些行囊的小样，大家正打算直接借用匠人自带的画像。不改的话，客人在工坊里删一条记录，匠人的画像也会跟着消失。

「路径已经安排好了，」魔女在图纸上画了一道岔，「小样不归我们的，就不碰。」这道护栏在第一天就补上了。

陈列大厅里也新开了一扇门，叫「壁纸」，和「本地 / 网络 / 网页」并排。推开它，插件小精灵们便自己跑去异次元的大集市翻找，带回三处来源：创意工坊里订下的、故乡自带的样板、旅人亲手做的作品；也可以随手指一个文件夹，由识路的小精灵判断那是一只行囊、一整座工坊，还是一整个库房。匠人打的标签，挂成大厅里的标签画册。

## 第一段：流光

最先入门的是流光画卷。表面上它只是一段影像，但魔女没有草草放行，而是先摊开故乡的古文书，看那边究竟怎么放流光。

答案出乎意料地朴素：故乡**从不另做一份流光**。不转制，不按窗子大小另裁一份，古文书里只有借来解读影像的入口，连织造影像的工具都没有。所谓缩放、对齐、翻转、底色、快慢、音量、明暗与色彩，全是放映时现场调出来的，每卷各有一套，来自匠人写下的默认值，加上故乡自己补的一组标准旋钮。

「那我们也照这样。」kamechan 说。工坊只放原卷，在桌面那扇窗里现场复现这些旋钮。只有某卷流光故乡能放、工坊的琉璃窗放不了时，才另织一份能放的副本，收在工坊自己的库里，不碰行囊。

本来还想过一条近路：叩某个门牌时，自动跳到行囊里的那卷流光。一试，琉璃窗里的放映机跟着这一跳之后报了格式不认。于是定下：每卷流光都备好一条「直达的路」，要么是原卷，要么是副本；陈列大厅的预览、工坊的背景幕布、桌面，一律只走这条路。

当天，流光这一段完成，初步试映过了。

## 第二段：纸窗，先学会故乡的礼数

纸窗箱庭是一扇扇会动的纸窗，窗里是真正的网页。故乡用自己的琉璃窗打开它们，并在窗里预先摆好一套「礼器」：窗里留一个应答人，故乡在开场时、旋钮被拧时、暂停时、全局设置变化时都去喊它一声；窗里还能留话，请故乡把正在响的音乐的音柱、歌名和封面送进来。

所以这一段的本质，是让工坊**扮演箱庭的故乡**：把纸窗按原样请进来，在窗里的咒语开口之前摆好同样的礼器，再由工坊站在故乡的位置上往里送东西。

动身之前，魔女先编了一部礼数大全：故乡的公开文书、带回来的样例、古文书里查到的条目、旅人们的传闻，每一条都注明出处。主样例选了辉夜姬那扇纸窗：它的咒语被打乱过，一理顺就会转死，只能原样读；歌单、封面、歌词，全靠读同一只行囊里的一份清单。往后每一段的验收，都以它为准。

古文书里查到的事实，决定了整场仗的打法：故乡给每扇纸窗单开一座小屋，窗里以「本地之物」的身份打开，还拆掉了琉璃窗的一道围墙，所以窗里能随意翻读行囊。但故乡另设了一道关卡：读本地之物，必须落在这扇窗自己的行囊里，否则拒之门外，还要记一笔。

## 第三段：一扇只通向自己行囊的门

起初，大家照老办法，把纸窗装进工坊里的一扇小窗，再让工坊门口支起的一个小驿站把窗里的东西送过去。隔离是做到了，纸窗碰不到工坊的任何东西；可它也读不了行囊，而且小驿站每次开张门牌号都不一样，窗里存下的东西随之丢失。

十月二十七日，探索队做了一回先导试验：直接以本地之物的身份打开辉夜姬那扇窗。外壳出来了，正中却一直停在「Loading...」——它去读那份歌单，被琉璃窗挡了回去。临时把整座工坊的那道围墙拆掉再试，歌单读到了，歌曲、封面、字幕、时钟一应俱全，音乐自己响了起来。可同一阵风里，窗里也能读到工坊脚下大地的系统文书，能翻到别的纸窗的行囊。

「这道墙一拆就是全拆，连陈列大厅都敞着。」魔女皱起眉。于是琉璃窗上刻了一道新纹，让那道围墙只对指定的窗拆开；再照故乡的样子设关卡，越出行囊的请求一律拦下。门禁这样够了——探索队就此定下，桌面上的纸窗从此以本地之物的身份直接打开。

鼠标也照故乡的规矩。古文书里写着，故乡并不在大地上埋伏，而是每秒两百次地看一眼光标在哪、左键按没按；移动一律转达，按下只在光标真落在桌面上时才转达，滚轮和键盘一概不传。第一版就只做移动和左键。

## 第四段：替身、门禁与一道道新纹

十月二十八日，「替身」登场。它是一个小小的咒语精灵，抢在纸窗开口之前进场，替窗里摆好故乡的那套礼器；窗里要旋钮的值，它就向工坊讨一份，之后再竖起耳朵听变化。以本地之物身份递来的请求，只能领到一张专为纸窗写的通行证，上面寥寥几项。通行证没限定能听哪些消息——这一点大家商量过，认定可以，也算工坊开放给纸窗的一份能力。

接下来几天，探索队沿着同一个方向一步步推进：

- **预览也走本地之物。** 陈列大厅预览里的小窗原本还靠小驿站，大家想让它和桌面走同一道关卡。可工坊给小窗换上本地的门牌，被琉璃窗挡下；换个法子从后院硬闯，结果把作画的小屋撞塌了，整扇窗刷新，预览重新挂上又闯一次，循环不止。「不绕路。」魔女合上书，「正正经经再刻一道纹。」新纹只给工坊自己的主厅开这扇门，放谁进来仍由关卡按行囊裁决。
- **大厅里的图与流光也走本地之物。** 定下的形态是：主厅完全放开，小窗按各自的行囊限制。
- **桌面不再开小驿站。** 插件小精灵们的文件，改由工坊直接递过去，不另起新的门路；小乌龟顺手关掉了一条对所有窗子都敞着、却从没人走过的旧路。
- **把画拖出窗外。** 原先在 Windows 的大地上拖出一张画，要绕一大圈：先送到临时处，再交给那片大地的管家。两轮暗中记账证实东西确实送到了，松手之后管家手里却仍然空空。大家决定不再修这条弯路，把 Linux 与 macOS 的大地上已经做好的「直接递真画」搬过来。
- **旋钮面板。** 面板不照搬故乡的模样，用工坊自己的表单，缺什么再补。客人拧过的旋钮，记在这张画自己的档案里，只记和匠人默认值不同的那几个；每拧一次，档案换一个新编号，各处收到消息就重讨一份，再学着故乡的口吻告诉纸窗。

## 第五段：十七次里的十二次

十月三十一日，旋钮面板做好，进入实地回归。怪事出现了：桌面切换到纸窗，十七次里有十二次，替身最早递出的请求被拒，理由是「来源不明」。其中三次连旋钮的值都没讨到，桌面上那扇幻灯片纸窗只显示一行字，请人去设置里选目录。

「是琉璃窗本身的脾性吗？」kamechan 问。几支小精灵探索队翻遍了琉璃窗的营造图，答案是：它本就如此。琉璃窗记着的「这扇窗此刻在哪一页」，要等整页换完才改；而新一页最早的几句话，往往在那之前就已说出口，被认成了空白页，或者上一页。

更糟的事，藏在同一道时差里。工坊另有一条备用的传话路，认不出来源时，会退回到「这扇窗最初打开的那一页」，也就是工坊的主厅。纸窗在这一瞬间，会被当成工坊自己人，拿到整座工坊的钥匙。一个旋钮偶尔失灵的小毛病底下，藏着一扇暗门。

于是改用「换页那一刻琉璃窗就已认定的发信人」来认来源；备用路上遇到来路不明的，直接拒绝，不再将就。修好再试，十五次切换，零失败。

## 第六段：来自哪里，与是谁

可这还不是终局。同一天，另一支小精灵探索队已经把预览和桌面统一成同一种模样：两边都是工坊里装着纸窗的小窗，工坊要凭来信的完整门牌，认出「是哪一扇纸窗在讨旋钮」。而「发信人」只写到城名、不写门牌，所有本地之物写的都是同一座城。两支队伍的成果合到一起时撞上了：只看发信人，认不出是哪一扇；看窗子记着的门牌，时差又回来了。合并一度停下。

魔女把问题拆成两半：**来自哪里**，只看发信人就够；**是谁**，却需要一个发信人给不了、纸窗又伪造不了的完整门牌。几条近路都被她一一划掉：信封上的回邮地址，本地之物根本不写，纸窗还能自己改；让替身把门牌报上来，纸窗一样能冒充；在换页那一刻记下门牌，记账的人站在另一条线上，先后照样对不上。

一个不动琉璃窗的折中方案被否了。最后的办法，是在琉璃窗上再刻一道纹：琉璃窗在为新一页安排「送信人」的那一刻，本来就确切知道它替谁送信，就在这里把门牌记下，写进这一页往后递出的每一封本地信里，纸窗改不了。来自哪里、是谁、能不能进行囊，三处从此都看同一个事实。在还没刻上这道纹的窗子上，纸窗宁可整扇打不开，也不留暗门。

回归时还抓到一桩：纸窗之间直接切换时，新小窗偶尔整页都没接上和工坊说话的那根线，桌面随后几次心跳无人应答，守门人只好把整页重开。查下来，是琉璃窗里同一间屋子可能同时住着两个同名的房客，旧的走得慢，走时把新来那位的登记也一并划掉了。修好后复测，三十四个新页面个个都接上了线、请到了替身。

也是在这一役里，探索队立下一条往后一路沿用的规矩：先把看到的报告清楚，再商量下一步。

## 终章：听见音乐

十月三十一日，工坊里还只有一块屏幕可试，原定的「桌面收尾」一段继续搁着，先做音乐与媒体；预览和桌面两边都要听得见。

照故乡的样子做：纸窗留话要听音乐，替身就向工坊订一份，并递上一条只通往这扇小窗的专线；工坊从大地上接出正在响的声音，拆成高低不同的一排音柱，约每秒三十次送过去，又盯着大地上正在播的歌，把歌名、歌手、封面和进度送进窗里。没人订就不听；只给匠人声明过「会随音乐起舞」的纸窗放行；小窗一关，专线随之拆掉。试验的主样本是「音域回响」那扇窗，没有声音时，它会显示一片静静起伏的波浪。

十一月一日凌晨，这一段落定，网页之役告一段落。七天里，琉璃窗上新刻了四道纹，桌面上再没有小驿站，纸窗在预览和桌面上走同一条路、守同一道门。

同一天中午，第一位通译走进了工坊，身后跟着一座座封在玻璃里的箱庭。真正的远征从这里开始。
