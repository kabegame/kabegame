# 壁纸纪

> Kabegame 壁纸魔法工坊探索异次元箱庭的纪年。始于十月二十五日，成书于十一月十九日。
> 这是一部故事，不是说明书。要查规矩与数字，以 `3-scene/` 等目录下各阶段的计划与报告为准。

---

## 题记

工坊之外，有一个异次元。

那里漂浮着无数箱庭：一座座封在玻璃里的小世界，有层层叠叠的风景、会发光的星尘、会念咒的小生灵。它们只在故乡的法则下醒来。那法则从不写在明处，藏在古文书的字缝里，只肯在它运转的那一瞬露出真容。

看板娘 kamechan 想把这些箱庭迎回工坊，让它们在这里也醒过来，和在故乡时一模一样。背上的小乌龟、路径魔女和插件小精灵们，陪她走了这一路。

二十六天之后，迎回工坊的 293 座箱庭里，292 座的封印都已解开。

## 读法

各卷大体按开工先后排列，但很多卷是同时推进的：同一天里，可能有五六支小精灵探索队各守一片箱庭。所以卷与卷之间的日子会交叠，一卷里说的「后来」，可能发生在后面几卷的中途。

每卷开头一行写着日子和一句话概括，只想知道大意的读者，读这一行就够了。
