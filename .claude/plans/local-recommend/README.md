# 本地推荐 —— 总计划（思路）

本文只记思路、已倾向的决策与待定事项，不含现状锚点与逐点代码；各期细化时再拆分文件。

---

## 总体设计思路

推荐只服务一个用户，且全部在本地运行，没有「别的用户」可借鉴，所以不走协同过滤（矩阵分解、靠多人共现做的物品协同），而是**基于内容的过滤 + 用户本人的行为反馈**。这里有两件互相独立的事：向量与特征只**描述图片**，用户行为才说明**用户喜欢哪些**。没有行为数据，模型什么也学不到。整个推荐是一个循环：行为 → 样本 → 训练偏好模型 → 给候选打分 → 生成推荐列表 → 新的行为。

**行为是唯一的真源。** 用一张事件表记录原始行为，每条带上下文（推荐页 / 画廊 / 轮播 / 预览）和在列表里的位置。收藏、隐藏、删除、设为壁纸、托盘「下一张」由后端从已有事件推导，前端只补报两样：曝光（图在视口里出现过）和预览停留时长。训练样本、样本权重、偏好模型都从事件表现算，**不持久化模型**：单个用户最多几万条事件，每次生成推荐前全量重训只要毫秒级。所以换嵌入模型、调权重、修 bug 都只需要重训一遍。冷启动用库里已有的收藏、隐藏和 `last_set_wallpaper_at`，第一天就有样本，只是这些样本缺曝光信息，权重给低一些。

**图片的描述分三层。**
- 人工特征：标签、作者、来源插件、色盘、宽高比是否匹配屏幕、媒体类型、新鲜度、距上次设为壁纸多久等。
- 视觉向量：CLIP 家族模型，用户可以选模型。
- 文本向量：用同一个模型的文字编码器，只编码有语义的自由文本，包括标题、描述、WPE 简介、AI 生成图的 prompt。

文本要先分类。作者名、来源、id 这类标识性文本没有语义，做类别特征，不进向量。用户标签改得最频繁，走特征，不进文本向量，这样文本向量几乎不用重算。和内容无关、却会影响行为的因素也各自单独成特征，比如媒体类型、本机能否实时渲染、行为发生的场景。这样「嫌视频壁纸耗电」「场景在本机只显示静态预览」造成的冷淡，由这些特征吸收，不会被学成「不喜欢这个画面」。

**偏好模型是加权逻辑回归。** 输入是 `[图片向量; 文本向量; 有无文本; 人工特征]`，带 L2 正则和按时间衰减的样本权重，文本占多少分量由反馈决定，不手调。学到的权重就是向量空间里「用户喜欢的方向」。人工特征的权重同时用来给出推荐理由。不选模型时只用人工特征，这也是冷启动期的兜底。

**生成和读取分开。** 推荐不能写成一个排序段，原因有四个：
- 打散、限额、探索都依赖前面已经选了哪些图，`ORDER BY` 只能给每行一个独立的键；
- 模型状态在路径之外，会随反馈变化，两次翻页之间顺序可能就变了；
- 推荐要记曝光，而读路径不应产生写入；
- 事件刷新会让列表在用户眼前重排。

所以**生成是 core 命令**，流程如下：
1. 取候选路径，即当前视图的过滤部分，原样复用 PathQL 的过滤语言；
2. 给全部候选打分，取前几百张；
3. 按相似度打散（MMR）、按来源限额，并留出探索名额；
4. 追加写进一张物化列表表。

**读取仍然走 PathQL**：新增排序段 `sort/recommend-<listId>`，INNER JOIN 物化表、按位置排序，形态和 `by-album-order` 一样。列表一旦写入就不变，所以：
- 翻页稳定，`~~/rank` 定位、ImageGrid、预览、字段补丁照常可用；
- 被删的图因为 JOIN 自然消失；
- 列表**只追加**：「加载更多」往同一个列表后面续写，「换一批」生成新列表；
- 推荐视图只在已持有的行被删除时刷新，新图入库不刷新。

**嵌入模型由用户选择，运行时用 ONNX。** 一个模型就是一个 ONNX 文件加一份描述清单，清单里写预处理参数、向量维度、有没有文字编码器、支持的语言、许可。加模型不用改代码，以后要开放「导入自己的模型」也只是多一个界面。具体做法：
- 模型不随安装包附带，选中后才下载，下载完校验 sha256，国内走镜像或自有 CDN；
- 默认只下图片编码器，打开文字搜图时再下文字编码器；
- 选模型时先拿几十张缩略图在本机实测，给出每张耗时和全库预估时间，用户确认后再开始补算。

不同模型的向量不能混用，所以向量按 `(image_id, model_id)` 存。换模型时旧模型继续提供推荐，直到新模型补完全库再一次切换。补算由一个「嵌入补齐」后台服务负责：循环找「当前模型下缺向量」或「文本哈希对不上」的图，分批计算。状态就是向量表本身，所以换模型、新图入库、崩溃续跑、模型晚下载都由同一个循环处理。它不走回填作业框架（那套是迁移登记的一次性作业），入库流程也不碰模型。

**视频与 WPE 壁纸。**
- 视频：均匀抽帧（复用色盘的取图来源规则），各帧编码后取平均、再归一化。另加运动强度、时长等人工特征，补上 CLIP 看不到的「动」。
- WPE 网页 / 场景壁纸：默认用预览图（动图抽帧）。用户实时观看时，借封面功能的截图链路顺手采样，得到带用户属性的真实画面。另外在入库时静态解析工程文件，得到结构特征：粒子、effect、脚本、声音、音频响应、鼠标交互、属性个数。工坊标签已经是现成的标签。
- 「本机能否实时渲染」单独作为一个特征。

**轮播。** 轮播路径指向一个固定名字的推荐列表，快播完时由生成器往后追加。因为列表只追加，现有的位置语义保持成立。探索用 bandit：被跳过记负，停满间隔记弱正，收藏记强正。

## 关键决策与理由

1. **不做协同过滤。** 只有一个用户。「众人的知识」通过两个途径进来：预训练的视觉模型，以及插件 metadata 里的源站热度（当特征用）。
2. **生成和读取分开，物化列表只追加。** 打散、探索、模型状态都不是逐行排序能表达的；物化之后又能完整复用 PathQL 的读取、分页、定位和事件机制。
3. **偏好模型不持久化，每次从事件表全量重训。** 取代之前设想的在线 FTRL：数据量小，全量重训没有状态，不会坏，换模型也能重训。
4. **运行时用 ONNX，首批先给精选模型列表。** 模型就是数据；之后开放导入不用改底层。代价是要打包 onnxruntime 动态库。
5. **向量由嵌入补齐服务异步补算，入库流程不碰模型。** 模型可选、可能还没下载、可能更换，补齐循环能统一处理所有这些情况。
6. **干扰因素单独成特征。** 媒体类型、能否实时渲染、行为场景，与内容偏好分开学，互不污染。
7. **人工特征始终保留。** 它负责推荐理由、冷启动，以及不选模型时的兜底。

## 行为信号与初始权重

权重是初始猜测，要靠实际使用来调。

| 行为 | 标签 | 权重 | 备注 |
|---|---|---|---|
| 删除 | 负 | 5 | |
| 收藏 | 正 | 5 | |
| 设为壁纸 | 正 | 4 | 作为壁纸保持越久越强（取对数） |
| 隐藏 | 负 | 4 | |
| 改过用户属性、设过封面 | 正 | 3 | WPE 壁纸的投入信号 |
| 轮播中手动跳过 | 负 | 1～2 | |
| 预览停留 | 正 | 随时长增加 | 封顶后取对数；窗口失焦时停表；按类型比较；视频按「看了几遍」 |
| 预览 1 秒内关闭 | 负 | 0.5 | 快速连续翻看不全算 |
| 轮播停满间隔没跳过 | 正 | 0.5 | |
| 出现在推荐页视口里但没点开 | 负 | 0.1 | 必须有，否则只有正样本；在画廊里自己翻过的不算 |
| 从没给用户看过 | — | — | 不进训练 |

## 待定事项

1. **入口**：做成独立的「发现」页（倾向这个，工具栏换成「换一批 / 加载更多」），还是画廊排序下拉里的一项。
2. **列表回收与收藏视图**：只保留最近 N 个列表；收藏视图改存生成参数、打开时先生成一次，而不是存 `recommend-<listId>`。
3. **轮播**：用固定名字的列表追加，还是每轮重建；bandit 用 Thompson sampling 还是先随机留位。
4. **首批模型与多语言**：日文、中文文本占比大，候选是 SigLIP 2、多语言 CLIP、Chinese-CLIP，需要在本机实测效果和速度后再定。
5. **插件 metadata 正文**：先只用干净的来源（标签名、WPE 标题与描述）。是否要插件声明「哪些字段是正文」（这会给插件契约加一个新概念），等效果验证后再定。
6. **平台**：先只做桌面，用 cargo feature 控制；Android 等小模型和实测数据出来再说。
7. **模型托管**：用 HuggingFace 镜像还是自有 CDN；放自有 CDN 前要确认各模型许可允许再分发。
8. **次要特征**：运动强度、渲染实测帧耗时、源站热度值不值得做。

## 分期

每期可单独合入。

| 期 | 内容 | 用户可见变化 |
|---|---|---|
| **P1 反馈事件** | 事件表；后端从已有事件推导；前端上报曝光与停留 | 无 |
| **P2 特征推荐** | 人工特征、偏好模型、生成命令、物化列表、排序段 `recommend-<listId>`、推荐入口 | 有推荐（只用人工特征） |
| **P3 视觉向量** | ONNX 运行时、模型清单与下载、嵌入补齐服务、设置页选模型与本机实测 | 可以选模型，推荐变准 |
| **P4 文本向量与文字搜图** | 文字编码器、分词器、多语言、文本哈希 | 可以用文字搜图 |
| **P5 视频与 WPE** | 抽帧平均、结构特征、观看时顺手采样、「能否实时渲染」特征 | 视频与 WPE 壁纸的推荐变准 |
| **P6 轮播** | 固定名字的推荐列表、bandit | 轮播可以按推荐选图 |
| **P7 文档与回归** | cocs、AGENTS、回归文档、changelog、真机勾选 | — |
