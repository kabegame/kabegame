# Kabegame 发布日志漫画

## Kabegame 世界观

一个魔法异世界，Kabegame 应用界面像一座“壁纸魔法工坊”，左侧导航是通往不同房间的传送门，画廊是壁纸陈列大厅，画册是分类收集仓库，「源」页是召唤新壁纸的插件魔法小店，任务抽屉是远征委托板，设置弹窗是魔法调律室（从 kamechan 的工具箱里打开）。

看板娘kamechan(かめちゃん)是 Kabegame 的桌面守护者，也像工坊里的小管理员。她不会战斗，不会魔法，而是用温柔、实用、带一点俏皮的方式整理壁纸收藏。

她有一个小乌龟壳背包精灵搭档。它有两个形态，独立的小乌龟和背在背上的两种形态。平时它被背在看板娘背上，是可爱的小乌龟壳背包；需要帮忙时，它可以从背包形态化为小乌龟助手，拿路牌、盖章、推小车、举检查表、搬相册盒子、压住乱飞的刷新纸条。它的存在是治愈和轻松。

PathQL 魔女是 Kabegame 工坊里的“路径魔女”，是一个可爱、聪明、稍微有点小得意的魔女。她负责把复杂的壁纸数据变成可以走的路径，把画廊、画册、任务详情、插件和虚拟磁盘连接到同一套路径规则里。她会施展路径おまじない，让 Provider 过滤树发光、分页轨道对齐、插件入口自动接到正确房间。 她手里拿着路径魔法书、卷轴或发光路标，身边漂浮着 `/gallery`、`/albums`、`/plugins`、`fetch`、`count`、`children` 这类短路径符号。她的魔法特效应该是细细的路径线、发光节点、目录树、书签和小型传送门。

PathQL 魔女和 kamechan 的关系是帮忙整理工坊的伙伴。kamechan 负责整理壁纸收藏并可爱地展示它们，PathQL 魔女负责让背后的路径和规则稳定运转。两人同框时，看板娘更元气治愈，PathQL 魔女更理性、俏皮、像在说“路径已经安排好了”。

异世界魔法元素要轻量：

- Provider 过滤树可以像发光的魔法路径树。
- PathQL / DSL 可以像工坊里的路径咒文或目录魔法书。
- Provider 路径则像咒语。
- 插件是一个个呆萌可爱的小精灵，不同网站的插件有不同的配色。
- 画册可以像收纳宝箱、相册房间或轮播舞台。
- 任务可以像远征委托，进度条像魔法能量槽。
- 应用内背景图可以像把壁纸铺成舞台幕布。
- 设置项可以像调律仪表、滑杆和开关咒具。

现代软件 UI 占主体，魔法元素作为装饰和视觉隐喻。UI 结构必须清楚，不能被魔法特效遮住。整体氛围是“二次元开源壁纸工坊的一天”，轻松、治愈、带一点小コント。

## 页面布局设定

### Kabegame 画廊页布局

用途：

当漫画主题与图片收集、图片筛选、搜索、图片尺寸 / 格式 / 名称、壁纸设置、视频缩略图、分页、空状态相关时使用。画廊是 Kabegame 的核心页面。

页面结构：

左侧是窄窄的 Kabegame 主导航，顶部是看板娘头像，下面只有一列图标：画廊、画册、源、畅游、运行配置；当前页（画廊）的图标块是粉紫渐变高亮。右侧主内容区是画廊，分成四层：第一层是标题卡片，第二层是查询 chip 条，第三层是翻页条，第四层是图片网格。不要把所有按钮塞进同一条工具栏。

第一层是一张圆角白色标题卡片。左侧是粉紫色大标题「画廊」，下面一行小字「共 2522 张图片」。右侧只有四个控件：刷新（圆形按钮，循环箭头图标）、失败图片（圆形按钮，感叹号图标，右上角带红色数字角标）、任务抽屉（紫色实心圆形按钮，清单板图标）、主按钮「+ 开始收集 ▾」（粉紫渐变胶囊按钮，下拉里有「本地」「网络」「网页」三项）。

第二层是查询 chip 条：一排独立的圆角小方块图标按钮，每个按钮就是一个查询维度，不需要先点「筛选」才展开。从左到右：排序、顺序（正序 / 倒序切换），一条细竖分隔线，然后是搜索（放大镜）、时间（日历）、插件（拼图）、媒体种类（图片框）、比例（屏幕框）、尺寸（叠层），最后是一个带文字的胶囊「A 高级 ▾」。条的最右端单独放一个「…」按钮，用来选择哪些 chip 显示在条上。点任意 chip 都会在它正下方弹出一个轻量 popover。

第三层是一条浅粉色翻页条：左端「‹ 上一页」按钮，右端「下一页 ›」按钮，正中是页码牌，形式是「7 ╲ 26」——当前页是粉色大数字，总页数是紫色数字，中间用一条细斜线隔开。

第四层是大量二次元壁纸缩略图组成的四列网格，图片按原比例显示，竖图横图混排，卡片之间留白，像壁纸收藏库。网格右下角悬浮两个粉色圆形按钮（回到顶部 ↑ / 滚到底部 ↓）。

标题卡片具体元素：

「共 2522 张图片」放在标题正下方，表示当前画廊总图片数。右侧圆形按钮都很小、白底细边框，只有任务抽屉是紫色实心。「+ 开始收集 ▾」是整页最醒目的按钮，收集入口统一在这里（本地导入、网络插件收集、网页收集都从它的下拉进入），不要另外画独立的「导入」按钮，也不要画快速设置、帮助按钮。

查询 chip 条具体元素：

chip 是白底、粉紫细描边的圆角小方块，只有图标没有文字（「A 高级 ▾」除外）。某个维度生效时 chip 变成高亮描边。点开 chip 后的 popover 举例：搜索 chip 弹出「关键词输入框 + 全选勾选框」，下面是「搜索范围」的六个勾选项（显示名称、本地路径、链接、元数据、原生元数据、标签）和一两行灰色说明；时间、插件等 chip 弹出各自的选项树。popover 半透明白底，小而精，贴在 chip 下方，不是铺满页面的大面板。

翻页条：

翻页条是独立的一整行，不和查询 chip 挤在一起。页码牌「7 ╲ 26」居中，斜线把当前页和总页数分开；不要画成一排 1 2 3 4 5 的页码按钮，也不要放到页面底部。

空状态：

画廊为空时，主内容区中央显示看板娘坐在打开的空相册盒子旁，手拿空白图片卡，小乌龟在旁边。台词可为「啊哦，这里还什么都没有呢」。

避免：

不要把画廊画成普通照片墙而没有标题卡片和查询条。不要只画一个大图而没有网格。不要画出「导入」「快速设置」「帮助」按钮或「每页 100」下拉——当前界面没有它们。不要把查询条画成带文字的长按钮行或一个「筛选」总开关。不要在缩略图角落加任何小标签。不要出现过多不可读小字。

### Kabegame 图片预览与幻灯片播放布局

用途：

当漫画主题与图片预览、预览幻灯片自动播放、播放方向、预览跟随画廊翻页、图片标签面板、插件详情相关时使用。

页面结构：

在画廊（或画册、任务详情）的网格里点一张图，会弹出一个几乎占满主内容区的大圆角白色预览弹窗；背后的画廊被半透明灰紫遮罩压暗，但仍能隐约看见网格和翻页条。弹窗顶部是一条淡粉紫渐变标题栏，左侧是图片名（例如「bakemonogatari / sengoku nadeko / camui1104」），右上角是细细的 ✕ 关闭按钮。主体分三栏：

- 左栏是信息面板，由几张可折叠的圆角小卡片竖排组成：「基本信息」（名称、源 + 插件小图标）；「标签」（一列浅色胶囊标签，每个后面带 ×，标题右侧有复制图标，底部两个描边按钮「+ 添加标签」「新建标签」）；「原生元数据」（标题旁一个粉色等宽小徽章，例如 image/jpg）。
- 中栏是大图舞台：图片居中按原比例显示，左上角和右上角各有一个灰色半透明圆形按钮，用来收起 / 展开两侧面板。
- 右栏是「插件详情」卡片：插件渲染的原站风格详情，衬线大标题加几组「分类名 + 彩色标签胶囊 + 数量」。

翻页与幻灯片按钮：

大图左右两侧边缘各有一组竖排的粉色按钮。上面是大圆按钮，用来切换上一张 / 下一张（‹ / ›，粉色实心）。正下方是一个更小的粉色圆按钮，就是幻灯片播放按钮，图标是双箭头（左侧 «、右侧 »）：点右侧的 » 会自动一张张往下一张放，点左侧的 « 会往上一张倒着放。播放时，这个小按钮里的双箭头会像传送带一样朝播放方向持续滚动；再点一次就停止。没有上一张时，左侧那组按钮不显示。

播放间隔在设置弹窗的「通用 → 预览幻灯片播放速度」里选：快（5 秒）/ 中（10 秒）/ 慢（20 秒）。

预览跟随翻页：

预览自动或手动翻到不在当前画廊页的图片时，背后被压暗的画廊会跟着跳到那张图所在的页，页码牌从「1 ╲ 24」变成「2 ╲ 24」，网格里对应的缩略图带粉色选中边框。漫画里可以让遮罩后面的页码牌和网格轻轻翻动，表现「后面的画廊在追着预览走」。

### Kabegame 设置弹窗布局

用途：

当漫画主题与应用设置、预览幻灯片速度、预览跟随翻页、壁纸轮播、应用内背景、下载参数、插件默认配置、画册盘相关时使用。

桌面端的设置是一个浮在当前页面上方的大弹窗，从侧栏底部 kamechan 的工具箱气泡里的「⚙ 设置」按钮（或快捷键 ⌘,）打开；打开时背后的页面（画廊、画册等）被半透明灰紫遮罩压暗，但仍能隐约看见。

设置弹窗结构：

弹窗是大圆角白色卡片，几乎占满主内容区。顶部是一条淡粉紫渐变的标题栏，左侧写「设置」，右上角一个细细的 ✕ 关闭按钮。主体分两栏：

- 左栏是分类列表，竖排六项，每项是「线条图标 + 短文字」：通用、外观、壁纸、下载、插件、高级。当前分类是粉紫渐变的圆角高亮条。左栏底部有一行浅紫小字「Kabegame 4.5.0」。
- 右栏顶部是当前分类的小标题（粉色小字，如「通用」），下面是一行行设置。每行左侧是加粗的设置名 + 下面一行浅紫色说明；右侧是控件：开关（开时粉红色）、下拉框、或者一组「分段单选」胶囊（选中项是粉紫渐变实心，其余是浅色文字）。行与行之间有很淡的分隔线。

各分类具体元素：

- 通用：语言、启用 Kamechan、开机启动、图片点击行为、预览幻灯片播放速度（快 5 秒 / 中 10 秒 / 慢 20 秒）、打开链接方式、快速同步。
- 外观：画廊列数、每页显示数量、画廊布局、滚动方向、图片填充方式、预览自动跟随视图翻页（开关）、应用内背景。
- 壁纸：启用壁纸轮播、选择画册、当前壁纸、轮播间隔、轮播模式、壁纸显示方式、过渡效果、视频壁纸音量、视频播放速率、壁纸模式。
- 下载：同时运行任务数、最大并发下载量、下载间隔时间、网络失效重试次数、自动去重、去重时更新元数据、冻结网页、默认下载目录。
- 插件：导入推荐配置时默认启用定时。
- 高级：画册盘、挂载点。

漫画里每格只需要画右栏的两三行设置，并把主题相关的那一行（例如「预览幻灯片播放速度」的三段胶囊）画大、画清楚，其余行可以只画轮廓。

避免：

不要把设置画成占据整个窗口、带左侧导航高亮的独立页面，也不要在主导航里画「设置」「帮助」项。不要画帮助页或帮助抽屉。不要把设置弹窗画成系统偏好设置的灰色面板，它仍然是粉紫色的二次元壁纸应用。不要在设置行里塞太多文字，控件形状比文字更重要。

# 分页检票员
漫画主题：预览放映室会追上当前页

候选类型：有笑点小コント

为什么适合画：预览播放和翻页同步都是普通用户马上能感知的体验更新，很适合画成画廊里的小放映室。画面能同时展示画廊网格、预览层、设置速度三个具体 UI。

剧情角度：有笑点/小コント。讲同一更新内容，但把预览追页演成检票，最后用小乌龟助手认真检票制造反差。

对应更新点：
- 预览弹窗新增幻灯片播放能力，可从上一张或下一张方向自动切换，并在设置弹窗「通用」分类新增预览幻灯片速度选项：fast、medium、slow。
- ImageGrid 新增预览跟随分页：预览中的图片不在当前页时，会定位图片所在页并跳转；同时有 previewFollowPage 设置开关和对应测试覆盖。

```text
Kabegame 是基于 Tauri 的二次元壁纸爬取、管理、设置和轮播客户端。本漫画主题是 v4.5.0-preview 的预览放映室：预览弹窗支持向前或向后自动播放，设置弹窗里可调快中慢，预览跨页时画廊会自动跟随到图片所在页。第 1 格，左上：画廊页，kamechan 在画廊网格前拿着小遥控器，当前选中缩略图有粉色边框；左侧导航清楚显示画廊，顶部工具栏和分页器简化可读；她表情自信，准备播放收藏。第 2 格，右上：预览弹窗打开，大图像小电影院屏幕，左侧和右侧各有播放方向按钮；kamechan 按下右侧播放，后方分页器开始从「1 ╲ 24」跳到下一页；背包精灵化为小乌龟助手，拿着迷你检票夹从窗口边缘探头。第 3 格，左下：设置弹窗的「通用」分类叠在预览旁，显示「预览速度」三档单选，kamechan 切到「快」；画廊分页器连续翻动，几张缩略图排队经过预览入口；小乌龟助手紧张地给每张缩略图盖「已到页」印章，动作过于认真。第 4 格，右下：当前预览图和画廊页终于对齐，kamechan 满意看图；小乌龟助手却把自己的龟壳也盖上「第 2 页」印章，露出严肃工作脸；kamechan 吐槽式惊讶，形成反差オチ。版本更新点必须画清楚：预览自动播放、速度档位、预览跨页时画廊跟随定位。避免项：不要把自动播放画成桌面壁纸轮播，不要让小乌龟助手抢走主功能，不要出现长代码、真实视频站 UI 或不可读密集文字。
```

整体目标：

生成日系二次元应用宣传四格漫画的单格画面。最终四格会被组装成 2x2 漫画，阅读顺序是左上、右上、左下、右下。每次只生成其中一格，画面要像画师为开源壁纸管理工具画的轻量更新公告，不要像 AI 自动堆满细节的插画。重点是角色表情、清楚的 UI 结构、短小的剧情推进、舒服的留白和可读的对白。

最终四格版式：

- 最终成品是 2x2 四格漫画，不是竖向长图。
- 阅读顺序固定为：第 1 格左上，第 2 格右上，第 3 格左下，第 4 格右下。
- 每格固定为横向 3:2，推荐生成尺寸为 1536x1024 px。
- 四张单格拼成最终 2x2 成品时，推荐总尺寸为 3072x2048 px，仍然保持 3:2。
- 四格尺寸必须一致，不要混用不同分辨率或不同裁切比例。
- 每格边框清楚，圆角轻微，不要厚重黑框。
- 每格只讲一个动作或一个小变化，不要在同一格塞多个时间点。
- 每格都要留出对白框位置，避免角色、UI、对白互相遮挡。

单格生成模式：

- 每次只生成一张单格画面，不要一次生成 2x2 四格。
- 单格画面本身使用 1536x1024 px，保持 3:2 横向比例，方便后期拼成 2x2。
- 单格可以有自己的圆角边框，但不要画出其他三格的边框、草图或占位格。
- 当前要生成哪一格，以上方剧情里写明的「第 N 格，位置」为准，只画那一格的内容。
- 每一格单独生成时，都要保持同一套角色设计、色调、线稿、边框和 UI 简化程度，让四张图拼在一起仍然像同一篇漫画。

基础视觉风格：

- 高质量日系 anime mascot comic。
- 干净线稿，线条有轻微手绘感，不要像矢量贴纸一样完全机械。
- 柔和 cel shading，阴影块面简单，最多两层阴影。
- 配色以粉紫、浅紫、淡奶油色为主，粉色和紫色都要出现。
- 因为主角偏紫，背景可以多放一点粉色，让画面更轻。
- 少量绿色作为乌龟主题点缀，不要把绿色变成主色。
- 整体清爽、明亮、轻松搞笑、治愈。
- 像软件更新公告小漫画，不像大型商业海报、游戏卡面、插画集封面。

绘画感控制：

画面要有真实绘画的取舍：

- 每格只保留 1 个主动作、1 个主要 UI 区域、1 到 3 个辅助小物。
- 背景允许有大块干净色面，不需要每个角落都有图标、粒子、花纹或光效。
- UI 图标只画关键图标，例如画廊、画册、插件、路径树、下载、收藏、缩略图、分页器。
- 缩略图网格可以概括成整齐小色块，不要每张缩略图都画成完整插画。
- 魔法特效只用细线、发光节点、小星点，数量少而清楚。
- 线稿可以有轻微粗细变化和少量不完全对称，保持自然手绘感。
- 不要过度锐化，不要超高密度装饰，不要满屏发光，不要把背景画成复杂机械城市。
- 不要让衣服、头发、UI、背景都同时有复杂渐变和复杂纹样。
- 画面应该像“画师画得很干净”，不是“模型不知道停在哪里”。

构图原则：

- 主角通常占每格高度的 45% 到 70%，不要被 UI 淹没。
- UI 是背景和剧情道具，不是完整截图。结构要清楚，但细节要简化。
- 应用窗口可以占画面后方或一侧，保留左侧导航、主内容区、工具栏或卡片网格的基本轮廓。
- 每格视角轻微变化即可，不要频繁大透视、鱼眼、夸张镜头。
- 至少有一格让角色和 UI 产生明确互动，例如点开查询 chip、把缩略图放进画册树、给插件卡盖章。
- 白框或气泡周围留出干净空间，中文对白要容易后期添加。

对白和文字：

- 中文对白放在圆形或椭圆形对白框中。
- 字数要短，像四格漫画台词，不要长说明。
- 不要出现乱码、伪中文、密密麻麻的小字、长代码块、长 URL。

应用 UI 元素：

可以出现可爱的简化软件元素：

- 壁纸缩略图网格。
- 画册卡片、封面拼贴、小相册盒。
- 插件卡片、拼图图标、小工具包。
- Provider 路径树、查询 chip 条、翻页条、画册树。
- 下载进度、任务进度条、成功/失败小徽章。
- 收藏星标、导入按钮、设置滑杆、开关。

这些元素要像漫画道具，而不是完整真实截图。每格最多选择其中一到两类作为主视觉。

轻量魔法世界观：

Kabegame 应用可以像一座“壁纸魔法工坊”。魔法只是软件功能的可爱隐喻：

- 查询 chip 弹出的选项像发光路径节点。
- 画册像收纳盒或小房间。
- 插件像小工具包或插件小精灵。
- 任务像远征委托板。
- 设置像调律仪表。

避免项：

- 单格生成，不要一次生成 2x2 版式。
- 不要把阴影和高光做成厚重 3D 渲染。
- 不要画成过度精修的插画封面，保持轻松的漫画公告感。
- 不要在每张图角落里画序号，稍后会统一添加

最终输出要求：

1536x1024 px 单格横向漫画画面，最终可拼成 3072x2048 px 的 2x2 四格宣传漫画。柔和粉紫色调，清楚圆角边框，干净线稿，轻量手绘感，应用 UI 简化可读，角色表情丰富，信息量适中，有留白，有短对白框。整体像 Kabegame 插件 provider trees 漫画的同系列作品。
