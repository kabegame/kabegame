## 画廊工具栏计数成对刷新

`GalleryToolbar` 现在接收当前 `filter`，在首次进入、过滤变化和 `images-change` 后并行读取过滤后数量与无过滤总数；
两条查询全部完成后才整体提交“数量 / 总数”显示快照。`ImageGrid.totalCount` 只作为首次加载或查询失败时的降级值，
分页器原有的独立 live count 不变。
