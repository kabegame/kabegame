# v4.4.1 regression

本版回归 checklist。任何改动可预见的回归路径，要在上线前 check 完毕。
按「操作」一步步点，对照「预期」，通过就把最后一列勾上。

## 打开文件 / 定位文件

本版把「打开文件」「打开所在文件夹」「打开目录」这几个入口的底层实现整个换掉了，
外部表现应当与上版完全一致。涉及入口：图片详情的「打开文件」、图片右键的「打开所在
文件夹」、画册页与画册详情的本地文件夹与画册盘目录、设置页的当前壁纸与默认下载目录。

| 标题 | 环境 | 操作 | 预期 | 备注 | 是否完成 |
| --- | --- | --- | --- | --- | --- |
| 打开图片 | Windows | 画廊里选一张图 → 图片详情 → 点「打开文件」 | 系统默认看图程序打开这张图；**过程中不闪黑色命令行窗口** | 换一个视频再试一次 | [ ] |
| 打开图片 | macOS / Linux | 同上 | 系统默认程序打开这张图 | | [x] |
| 打开所在文件夹 | Windows | 图片上右键 → 「打开所在文件夹」 | 资源管理器打开，并且**这张图被选中高亮**，不是只打开了父目录 | | [ ] |
| 打开所在文件夹 | macOS | 同上 | Finder 打开并选中这张图 | | [ ] |
| 打开所在文件夹 | Linux | 同上 | 文件管理器打开并选中这张图 | 少数桌面环境不支持选中，此时应退化为「打开父目录」，不能直接报错 | [x] |
| 打开本地文件夹画册 | Windows / macOS / Linux | 画册页找一个本地文件夹画册 → 点打开目录 | 文件管理器**新开一个窗口**，定位到该文件夹 | | [x] |
| 打开画册盘挂载点 | Windows / macOS / Linux | 先挂载画册虚拟盘 → 画册页或画册详情点挂载点 | 文件管理器打开挂载盘根目录 | 需要先装好虚拟盘驱动并挂载 | [x] |

| 入口全量点检 | 任一桌面平台 | 把上面列到的每个入口都实际点一遍 | 没有任何一个入口提示「命令不存在」或「没有权限」 | 这次改了命令名，漏改的地方只会在运行时暴露，编译不会报错，所以必须逐个点 | [ ] |
| 画册盘驱动安装 | Windows | 设置里触发安装画册盘驱动 | 正常弹出 UAC 授权并安装成功 | 这条路径本次未改动，属回归兜底确认 | [ ] |
