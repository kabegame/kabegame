# v4.7.0 changelog

## 用户侧

### Added
- 预览视频与场景壁纸时，控制条上可以调播放速度（0.25×–4×），只对这次观看生效；壁纸设置里的「倍速」现在场景壁纸也用（原来只有视频壁纸），范围扩到 0.25–4。
- 设置「外观」新增「颜色主题」：清爽蓝（天蓝 + 薄荷青）、动漫粉（默认，即原来的粉 + 紫）、高级灰（石板蓝灰 + 香槟金）、清新绿（绿 + 暖阳黄）、优雅紫（紫 + 天蓝），都是浅色调，每个主题由主色和一个点缀色组成；主按钮改为主色到点缀色的渐变。切换立即生效，重启后保留。
- 「壁纸」收集新增来源「从 Steam」，直接导入你的创意工坊订阅：在导入对话框顶部把来源从「本机」切到「从 Steam」，扫码或用账号密码登录购买了 Wallpaper Engine 的 Steam 账号（邮箱 / 令牌验证码直接在表单里填），在「我的订阅」里按分级筛选、勾选要导入的壁纸（也可以一次选全部），或者在「工坊发现」里搜索（也可以直接填条目编号或工坊链接）、按热门 / 订阅数 / 评分 / 发布时间浏览整个创意工坊并勾选，Kabegame 把它们下载到 Wallpaper Engine 目录的 `projects/myprojects` 下并导入，不用装 Steam。已下载的壁纸不会重下，有更新的只下载变化的部分。设置里还没有 Wallpaper Engine 目录时（例如 macOS / Linux），会顺带把 Wallpaper Engine 下载到 Kabegame 的数据目录并自动设为「Wallpaper Engine 目录」，不用再从 Windows 电脑复制。登录在有效期内可以直接复用，密码不会保存。两个页签都会记住上次的排序与筛选；「选中本页未下载」一键勾上本页还没下载的壁纸；翻页最多到第 2500 页。从 Steam 导入的壁纸的来源地址是它的创意工坊主页，也会挂上 Steam 标签（以前作者没在 `project.json` 里写 `workshopid` 的条目两样都没有）。
- macOS 窗口模式支持多显示器：每块显示器都有壁纸（原来只有主屏）。设置页「显示器模式」可选「各屏复制」（所有显示器同一张，视频只有主屏出声）或「逐屏独立」：点显示器布局图里的一块屏，就能给它单独设当前壁纸、轮播路径、显示方式与过渡；轮播到点时每块屏各换一张。显示器拔掉后它的设置会保留，接回来自动恢复，用不上了可以在布局图下方「忘记」。
- macOS 原生模式支持多显示器逐屏独立：每块显示器各设当前壁纸、轮播路径与显示方式，轮播到点时各换一张；新接上的显示器自动换成它该显示的壁纸。窗口模式与原生模式互切时「逐屏独立」会保留。
- macOS 原生模式的壁纸显示方式新增「适应」「拉伸」「居中」（原来只有填充，铺法由系统决定），改了立即生效，每块显示器可以不同。
- 多块显示器逐屏独立时，图库「设为壁纸」、画册「设为桌面轮播」、查询行「用当前视图轮播壁纸」会先让你选显示器（默认选中默认显示器，双击即可），成功提示带显示器名；画册只在部分显示器上轮播时仍可设给另一块。托盘「下一张壁纸」只切鼠标所在的那块显示器。
- Wallpaper Engine 壁纸可以从另一台电脑复制过来（例如把 Windows 上的壁纸传到 macOS）：源电脑开启「设置 → 高级」里的 Web 服务器，这台电脑用「Kabegame 服务器」插件（0.3.0）收集。整个壁纸目录逐个文件下载到下载目录，一张壁纸一个文件夹，标签与创意工坊地址一并带过来，任务日志逐文件显示进度；本机已有内容相同的壁纸时不会多存一份（需开启「自动去重」）。两台电脑的 Kabegame 都需要 4.7.0 或更高版本。从图库删除这类壁纸只删记录，下载目录里的壁纸文件夹不会被删除。
- 本地导入（含把文件夹拖进主窗口或画册）现在能识别 Wallpaper Engine 壁纸目录：选中的文件夹本身或它下面某一层是壁纸目录时，整个目录作为一张壁纸导入，不再把里面的预览图和视频拆成一张张图片。拖进文件夹画册时整个壁纸目录会原样复制进同步目录。
- 文件夹画册同步目录里的 Wallpaper Engine 壁纸目录，现在作为一张壁纸出现在这个画册里，不再为它另建子画册；整个目录删掉后，对应的壁纸也从图库移除。旧版本已经为它建了子画册的目录保持原样；已经同步过的文件夹里原有的壁纸目录，要等这个文件夹下次有变化时才会被识别。
- 收集任务新增「失败重试」：在收集弹窗、网页收集与运行配置里打开开关并填 1–10 次，任务运行中失败后会立即用相同参数重新发起，取消不会重试。重试出来的任务带「重试 k/n」标记，点开可查看整条重试记录（从新到旧，已删除的任务显示占位），运行参数里能跳到原始任务。
- 「壁纸」收集现在也会导入 Wallpaper Engine 场景壁纸（含创意工坊打包的 `scene.pkg`）。少数简单场景（如自带的 eagleflag、deep_space、beach）已能在图库预览和桌面实时渲染，属性面板改颜色等即时生效；其余场景显示作者预览图，渲染能力会逐步加入。
- 场景壁纸支持图层效果链与颜色混合模式，自带的 Razer Vortex 现在可实时渲染；设置页壁纸分区新增「场景后处理」（跟随 WPE / 关闭 / 开启 / 超高，默认跟随 Wallpaper Engine 自己的后处理设置）。
- 场景壁纸支持泛光与 HDR：「场景后处理」为开启或超高时，开着泛光的场景按 Wallpaper Engine 的算法画出光晕（超高档另有 HDR 高光与更柔和的多级光晕），光晕本身与 Wallpaper Engine 的输出逐像素一致（相差不超过 1/255）；图库预览、应用背景与桌面同一档位，超高档 4K 场景多占约 90 MB 显存。Razer Bedroom 在「场景后处理」为开启或超高时可见光晕。
- 场景壁纸支持 Wallpaper Engine 场景脚本（SceneScript）的基础部分：Razer Bedroom 现在可实时渲染彩虹灯带，Razer Vortex 的「模式」属性生效；一段脚本的某个回调出错只停用该回调，其余照常运行；场景脚本的存储（如记住的拖动位置）会保留到下次打开。脚本读到的位置、颜色、角度等数值和 Wallpaper Engine 一样是单精度，逐帧累加的脚本与 Wallpaper Engine 的结果逐位相同。
- 场景壁纸支持图层层级与第一批粒子效果：子图层跟随父图层移动、旋转与显隐；粒子的发射、运动、淡出、振荡与透视粒子按 Wallpaper Engine 的方式模拟，并逐帧对照过 Wallpaper Engine 的输出。自带的 Shimmering Particles 与创意工坊 3062029089 现在可实时渲染；改粒子数量、发光、风格等属性即时生效，不重新加载。
- 场景壁纸支持更多粒子效果与纹理格式：R8 / RG88 / DXT1 / DXT3 纹理；粒子序列帧动画（含随机帧与混帧）；按时长、延迟或周期发射，盒形发射区；粒子的尺寸、透明度、颜色随寿命变化，尺寸振荡、旋涡、限速、湍流与随机偏移；折射与裁切粒子；粒子的颜色覆盖（改颜色属性即时生效，不重新加载）。这些都逐帧或逐像素对照过 Wallpaper Engine 的输出。创意工坊 2854083091、3799426930、3812822229、3829603837、1504316159、3820104696 现在可实时渲染；用植物摇摆效果的场景（如创意工坊 2418800402）摇摆速度和 Wallpaper Engine 一致。
- 场景壁纸的粒子支持跟随鼠标、吸引与排斥、拖尾与朝向：粒子可以跟着鼠标出生（图库预览与桌面都生效，填充、适应、居中等壁纸样式下都落在光标下的画面上），可以被场景里的某个点吸引或推开；挂在会动的图层上的粒子可以留在原地、不跟着图层跑；拖尾粒子按速度拉长；粒子的朝向（面向镜头、直立、固定方向）与 Wallpaper Engine 一致，挂在倾斜图层上的粒子也照样面向镜头。这些都逐帧或逐个角点对照过 Wallpaper Engine 的输出。创意工坊 1838478131、3832772446 现在可实时渲染。
- 场景壁纸的粒子支持绳状拖尾与更多运动效果：用「绳」连起来的粒子与粒子身后的轨迹拖尾、绕点环形或两点之间排布、按时间与噪声改变大小 / 透明度 / 速度、保持与某点的距离、靠近某点减速与涡旋，都按 Wallpaper Engine 的方式模拟和绘制，并逐帧对照过它的输出（绳的形状与贴图坐标逐顶点一致）。鼠标拖尾这类用绳画的场景（如创意工坊 2254685070）现在能实时渲染。
- 场景壁纸的粒子支持子系统与音频响应：粒子可以带自己的子粒子系统，跟着父粒子一起动、在父粒子出生或消失时迸出（如萤火虫周围的火星、闪电落下时的光晕），子系统的个数上限、出现概率与位置都按 Wallpaper Engine 的规则，并逐帧对照过它的输出；声明了支持音频的场景里，粒子的发射量与扰动会随正在播放的声音变化（Windows），频谱的处理与 Wallpaper Engine 相同，没有声音时这些粒子不发射，和 Wallpaper Engine 一致。创意工坊 3778592720、3811798465、1514925620 现在能实时渲染。
- 场景壁纸的粒子支持脚本控制：场景脚本可以暂停、停止、重新播放粒子，或手动补发粒子，粒子的数量、大小、速度、透明度、颜色与控制点也能由脚本或属性在运行中改（如随音乐变化的粒子数量与大小），时机与 Wallpaper Engine 相同；HDR 场景里粒子的亮度设置生效；一个粒子系统同时带普通粒子与拖尾时两者都会画出来。三处 Wallpaper Engine 的异常行为没有照搬：粒子自然停止后脚本重新播放会再次发射，脚本停止后改参数不会自行恢复发射，脚本补发时迸出的子粒子落在正确的位置。
- 场景壁纸的粒子支持更多颜色与群体运动效果：粒子颜色可以按色相分档随机（以属性里设的颜色为中心）或从一组颜色里随机挑；粒子之间可以像鸟群一样互相靠拢、对齐速度或彼此分开。都逐粒子对照过 Wallpaper Engine 的输出，几张只差这两项的场景（如鼠标跟随的彩色粒子、酒瓶倒水）现在可实时渲染。
- 场景壁纸的粒子支持光照：开了光照的粒子（如雷电周围的光晕、带法线图的粒子）按场景的环境光与灯着色，和 Wallpaper Engine 逐像素对照过；只差这一项的场景（如 Talia Yang 的雷电壁纸）现在可实时渲染。
- 场景壁纸支持声音：场景里的背景音乐与音效会播放，循环、单次、随机间隔三种播放方式，多首随机连播，以及作者设的音量（含音量属性），都按实测 Wallpaper Engine 得出的规则实现；场景脚本可以播放、暂停、停止声音和调音量。音量跟随设置里的「壁纸音量」，应用背景与暂停时不出声。创意工坊 1967162875、3827677885 现在可实时渲染。
- 场景壁纸支持视差、镜头抖动与缩放：开了视差的场景里，各图层随鼠标移动前后错开，形成景深感，移动的幅度、方向和跟随快慢都按作者的设置；镜头抖动与画面缩放也按作者的设定播放，属性和脚本改这些设置时即时生效。测试场景和 Wallpaper Engine 的输出逐像素一致。图库预览与桌面一打开，图层和跟随鼠标的粒子就按当前光标位置摆好，不用先动一下鼠标；应用背景不跟鼠标。另按 Wallpaper Engine 修正了几处判定（材质文件里的注释、透明图层的深度设置、编辑器留下的裁剪偏移等），不再把场景误判为不支持。创意工坊 3778549173、2272499163、2279259068、2381978484、2382002554、2382120706、2382121137、2570822804、2955749185、3000769374、3445915391、3818481122、3830255100 现在可实时渲染。
- 场景壁纸支持组合层、全屏图层与纯色图层：组合层（含可调整组合层、全屏组合层、项目组合层）取下层画面再叠加效果，带子图层的组合层把子图层画在自己的区域里、超出部分裁掉；全屏图层铺满整个画面；编辑器建的纯色图层按作者的颜色、贴图与效果显示；带 3D 旋转并开了透视的图层按透视显示；图片的边缘与自动尺寸也按 Wallpaper Engine 的规则处理。测试场景和 Wallpaper Engine 的输出逐像素一致（相差不超过 2/255）。创意工坊 1923929928、1333579536 现在可实时渲染；用到这些图层的其它场景大多还缺文本、木偶动画、视频等别的能力。
- 场景壁纸支持静态 3D 模型（正交视角的场景）：模型文件的各个版本、模型的多套材质（皮肤）、多个网格的前后顺序、背面剔除与画面外的模型不画，都按实测 Wallpaper Engine 得出的规则实现，测试场景和 Wallpaper Engine 的输出逐像素一致。Wallpaper Engine 自带的 Retro 现在可实时渲染；其余带模型的场景大多是透视视角，或还缺反射、音频频谱等别的能力，暂时仍显示预览图。
- 场景壁纸能编译创意工坊作者手写的全部着色器：Wallpaper Engine 能接受、以前被判为不支持的写法（向量宽度不一致的赋值与运算、数字当条件、多出来的 `#endif`、同名宏重复定义等）现在按 Wallpaper Engine 的规则编译，本机全部场景用到的着色器都能编译通过，画面与 Wallpaper Engine 逐像素一致（相差不超过 2/255）。创意工坊 3822495444、3831518461、3837598414 现在可实时渲染；其余用到这些效果的场景大多还缺视频、关键帧动画、音频频谱等别的能力。
- 场景壁纸支持 Wallpaper Engine 自带的流体模拟效果，以及效果里按选项开关的步骤与贴图：按 Wallpaper Engine 的规则处理，流体逐帧对照过它的输出。按图层缩放修正形状的创意工坊效果（如圆角遮罩）现在能用，画面与 Wallpaper Engine 逐像素一致。着色器里声明了却没用到的参数，不再让场景被误判为不支持。用到这些效果的场景大多还缺文本、音频、视频等别的能力，暂时仍显示预览图。
- 场景壁纸能画用到大量插值变量的创意工坊效果（如摆动效果 auto_sway、音频示波器）：这些变量按 Wallpaper Engine 的方式排布，不再因为超出显卡的接口数量上限而整张退回预览图，画面与 Wallpaper Engine 对照过。创意工坊 3585875739（音频示波器）现在可实时渲染；用到摆动效果的场景还缺别的能力，暂时仍显示预览图。效果里边缘宽度为 0 的平滑过渡（如示波器没有声音时的线条、VHS 干扰带宽度或摆动羽化调到 0）按 Wallpaper Engine 的结果计算，不再整张变亮或反相。
- 场景壁纸里只有一级的纹理（效果遮罩、视频等）改用和 Wallpaper Engine 相同的各向异性过滤：纹理被斜向拉伸采样时（如云层流动效果）边缘不再出现明显色差。
- 场景壁纸的 3D 模型按 Wallpaper Engine 的规则读取编辑器里画的材质遮罩用了哪些通道（自发光、金属度、粗糙度、反射）：以前这几项被忽略，带自发光遮罩的部位（如创意工坊 3706286085 里角色的手套和鞋）比 Wallpaper Engine 暗。用到它的场景还缺雾、阴影等别的能力，暂时仍显示预览图。
- 场景壁纸能编译更多创意工坊作者写的着色器：插值变量特别多的效果（如音频示波器）在显卡支持时照常渲染，直接写 HLSL 类型名（`float2` 等）的效果也能编译。创意工坊 3348595482、3612971233 现在可实时渲染。在循环前写了 HLSL 优化提示（如 `[loop]`）的效果也能编译，3784410673 现在可实时渲染。
- 场景壁纸支持视频：作为图层画面的视频（包括创意工坊打包在场景里的 4K 视频与 HEVC 视频）会循环播放，被隐藏的视频图层自动暂停解码，暂停壁纸时一起停；和 Wallpaper Engine 一样不出声。画面与 Wallpaper Engine 对照过，只在颜色剧烈变化的边缘有细微差别。创意工坊 3822149301、3824550659、3828359750 现在可实时渲染；其余带视频的场景大多还缺文本、音频频谱、关键帧动画等别的能力。HEVC 视频需要显卡支持硬件解码，不支持时这个图层显示为透明。
- 场景壁纸支持作者开放的自定义图片属性：在属性面板里给这类属性选一张图片、GIF 或 MP4 视频，场景里对应的图层或效果贴图就换成它，按 Wallpaper Engine 的规则从正中裁成需要的比例，改了立即生效、不重新加载场景；清空后回到作者的贴图。图片的解码、GIF 的合成与播放节奏都逐像素对照过 Wallpaper Engine 的输出，只有 JPEG 与视频在颜色剧烈变化的边缘有细微差别。创意工坊 3462279189、3783690410 现在可实时渲染；快捷方式图标这类贴图来源还没实现，用到它的场景仍显示预览图（系统媒体封面见下一条）。
- 场景壁纸支持音频频谱：声明了音频处理的场景里，读系统声音频谱的效果（频谱条、随音乐跳动的光圈等）会跟着正在播放的声音动，和 Wallpaper Engine 用的是同一份数据，测试场景逐帧逐像素一致。创意工坊 3502090109、3585875739、3825170583 现在可实时渲染；其余用到音频频谱的场景大多还缺文本、关键帧动画、媒体信息等别的能力。Windows 与 macOS（14.2 起）上有声音数据，Linux 上频谱保持为 0。
- 场景壁纸支持作者开放的自定义图片属性：在属性面板里给这类属性选一张图片、GIF 或 MP4 视频，场景里对应的图层或效果贴图就换成它，按 Wallpaper Engine 的规则从正中裁成需要的比例，改了立即生效、不重新加载场景；清空后回到作者的贴图。图片的解码、GIF 的合成与播放节奏都逐像素对照过 Wallpaper Engine 的输出，只有 JPEG 的颜色边缘和标清视频的色彩有细微差别。创意工坊 3462279189、3783690410 现在可实时渲染；快捷方式图标这类贴图来源还没实现，用到它的场景仍显示预览图（系统媒体封面见下一条）。
- macOS 上的场景壁纸也能用快捷方式属性了（比如应用栏的格子）：在属性面板里给它填一个文件、App、文件夹、网址或命令，场景里显示它的图标（图片、视频、PDF 显示内容缩略图，App 和文件夹显示系统图标），点一下就打开；命令在你的登录 shell 里执行，和在终端里敲一样（Homebrew、nvm 等配在 `.zshrc` 里的命令与别名都能用），从 Finder 启动 Kabegame 也一样。面板里的「文件」在 macOS 上叫「文件或 App」。
- Linux 上的场景壁纸也能用快捷方式属性了（比如应用栏的格子）：在属性面板里给它填一个文件、应用、文件夹、网址或命令，场景里显示它的图标（图片、视频以及文件管理器生成过缩略图的文件显示内容缩略图，应用和文件夹显示当前图标主题里的图标），点一下就打开。应用就是 `/usr/share/applications` 等处的 `.desktop` 文件；程序、脚本、AppImage 会直接运行；命令在你的登录 shell 里执行，和在终端里敲一样。面板里的「文件」在 Linux 上叫「文件或应用」。
- 场景快捷方式打不开时（路径不存在、命令拼错、应用没装等），看板娘会说出原因；在桌面壁纸上点的也在主窗口提示。快捷方式填网址时照你输入的样子保存，打开时才补 `https://`。
- macOS 上的网页壁纸与场景壁纸也支持媒体集成了：读系统「正在播放」的歌名、歌手、专辑封面、播放状态与进度（Apple Music、Spotify、浏览器与网页播放器等，只要出现在控制中心的「正在播放」里就行），设置页与预览设置里出现「媒体集成」开关。macOS 拿不到副标题与专辑艺人；切歌时可能有不到半秒先显示新歌的时长、后显示新歌名。
- Linux 上的网页壁纸与场景壁纸也支持媒体集成了：读正在播放的歌名、歌手、专辑封面、播放状态与进度（支持 MPRIS 的播放器都行，如 Spotify、VLC、Elisa、浏览器里的网页播放器），设置页与预览设置里出现「媒体集成」开关。同时有几个播放器时，显示最近开始播放的那个；都暂停时停在最后播放的那个。Linux 拿不到副标题，也没有「音乐 / 视频」的类型。
- Windows 上的场景壁纸支持系统媒体集成：显示正在播放的歌名、歌手、专辑封面，并随播放状态变化的场景（音乐卡片、唱片机一类）现在可实时渲染。标题、封面、颜色与刷新节奏都按 Wallpaper Engine 的规则，用同一个测试媒体会话逐项对照过它的回调和封面画面。创意工坊 2932157836、2974757317、3219908811、3355291946、3470764447、3482471820、3487328036、3823859141、3823864170、3837699827 现在可实时渲染。在设置里关掉「媒体集成」后，这些场景按没有媒体处理；macOS 和 Linux 上暂时没有媒体数据。
- 场景壁纸支持按属性切换的贴图（Wallpaper Engine 编辑器里的纹理变体）：在属性里切换选项，对应的贴图当场换成另一张，和 Wallpaper Engine 一样。用到它的场景（如 3817265356）以前直接退回预览图，现在可实时渲染。
- 场景壁纸支持 BC7 压缩格式的贴图：用到它的场景不再因为「不支持的纹理格式」退回预览图（如创意工坊 3816948983 的锦鲤与水面贴图）。
- 场景壁纸的自定义图片属性也能换粒子贴图了（落叶、花瓣一类按精灵表播放的粒子）：选了图，每个粒子就画整张图；清空后回到原来按精灵表播放的贴图，改了立即生效。Wallpaper Engine 运行中换图会把图当成原来的精灵表切成一格一格、要重新打开壁纸才画整张，这里不照搬。创意工坊 3799462430、3812473896 现在可实时渲染。
- 场景壁纸支持形状光束、图层对齐、图层互相引用与透明写入设置：编辑器里的光束形状图层按 Wallpaper Engine 的规则画出；图片图层的对齐方式（如左上、底部居中）生效，子图层不受影响，场景脚本也能读写；遮罩、混合类效果可以引用别的图层（包括隐藏的图层与文字图层，如被手表表盘引用的时钟）的画面；图层叠加效果时的边缘处理、像素风图层的不插值、材质的透明通道写入与「透明度覆盖」混合也按 Wallpaper Engine 的规则处理（以前个别图层叠加效果时边缘会露出另一侧的画面）。测试场景逐像素对照过 Wallpaper Engine 的输出，只在纹理缩小处有细微差别。创意工坊 3656079027、3668499717、3811764016、3812887609、3819646765、3821678218 现在可实时渲染；其余用到这些功能的场景大多还缺场景脚本、关键帧动画、木偶动画等别的能力。
- 场景壁纸支持关键帧动画：编辑器里给位置、旋转、缩放、颜色、透明度、效果参数、缩放镜头等属性打的关键帧会按 Wallpaper Engine 的规则播放（循环、往返、只播一次，子动画跟随父动画），改属性时动画接着走、不从头开始；动画值逐帧对照过 Wallpaper Engine 的输出。创意工坊 2251857160 现在可实时渲染。脚本也能控制动画（播放、暂停、停止、跳帧、调速）并收到动画事件，规则对照过 Wallpaper Engine；用到它们的创意工坊场景多数还要等光标与媒体交互，暂时仍显示预览图。
- 场景壁纸支持透视 3D 场景、相机对象、深度与透明排序：用透视相机的场景（相机路径、相机抖动）按屏幕分辨率实时渲染，对象之间的遮挡（深度测试、背面剔除）和半透明物体由远到近的绘制顺序都按 Wallpaper Engine 的规则处理；场景里的相机对象（含脚本移动相机、按属性切换多个相机、缩放镜头）能控制视角，粒子也会面向相机。测试场景逐像素对照过 Wallpaper Engine 的输出，几张真实壁纸的相机与矩阵也逐项对过，只在纹理缩小处有细微差别。创意工坊 dna_fragment、techno、neon_sunset 现在可实时渲染；其余带相机对象的场景还缺文本、骨骼动画等别的能力，暂时仍显示预览图。
- 设置页壁纸分区新增「场景反射」（跟随 WPE / 关闭 / 开启，默认跟随 Wallpaper Engine 自己的反射设置）。反射关着时，地面倒影这类读反射的 3D 场景按 Wallpaper Engine 的方式显示（倒影处是背景色），Wallpaper Engine 自带的 Arsenal、Audiophile、Fantastic Car 现在可实时渲染，逐帧对照过它的输出。反射开着时，3D 场景的地面倒影（模型、图像、文字、粒子的镜像）也会实时画出，规则逐项对照过 Wallpaper Engine，测试场景与这三张壁纸和它的输出逐像素一致。
- 场景壁纸支持太阳光斑（sprite 对象）：光斑随相机转动，被前景物体挡住时按 Wallpaper Engine 的规则逐渐变小变暗，和它的输出逐像素一致。Wallpaper Engine 自带的 Rice Pod 现在可实时渲染。
- 场景壁纸支持木偶（puppet）骨骼动画：编辑器里做的木偶图层按 Wallpaper Engine 的规则播放骨骼动画，多个动画层的循环 / 往返 / 单次播放、覆盖 / 按权重 / 叠加三种混合与淡入淡出都按实测实现；动画层的速度、显隐等属性改了立即生效、不重新加载；带效果的木偶图层先做完效果再贴到木偶网格上。骨骼矩阵逐帧对照过 Wallpaper Engine 的输出（多数逐位相同），测试场景与两张真实壁纸逐像素一致。创意工坊 2896608544、3203778110、3351072238、3354366708、3409595232、3811769317、3813473025、3814576310、3818986268、3828324728 现在可实时渲染；木偶的挂点、变形、骨骼透明度、裁切遮罩、脚本控制与骨骼物理还没实现，用到它们的场景仍显示预览图。
- 场景壁纸的木偶（puppet）支持挂点、骨骼透明度、表情变形与裁切遮罩：挂在骨骼上的头发、饰品、粒子跟着骨骼动；眨眼淡入淡出、嘴型表情变形（含负权重）按 Wallpaper Engine 的规则叠加；眼睛等部位的裁切遮罩按它的绘制顺序画。父图层被脚本或关键帧移动时，挂件晚一帧跟上，和 Wallpaper Engine 一致。测试场景与真实壁纸逐帧对照过它的输出。创意工坊 2964778792、3253330537、3463520581、3491865410、3500648585、3829467967 现在可实时渲染。
- 场景壁纸的 3D 模型支持骨骼动画、表情变形与挂点：模型的多个动画层按 Wallpaper Engine 的规则混合，隐藏时动画暂停；挂件可以挂在模型骨骼上。木偶的纹理通道（按动画在图上叠加通道贴图）也按它的规则绘制。测试场景逐像素对照过它的输出。用到这些功能的创意工坊场景还差雾、阴影、精灵表动画等别的能力，暂时仍显示预览图。
- 场景壁纸的场景脚本能控制木偶（puppet）与 3D 模型的动画层：
  - 点击播放动作、错开各动画的起始帧、随音乐调节动画速度；
  - 动画层播完一轮时通知脚本；
  - 动画里的事件交给脚本。
  
  规则和生效时机都照 Wallpaper Engine 实测（脚本的操作在下一帧生效）。另外放宽了场景纹理的尺寸上限，和 Wallpaper Engine 一样到 16384，以前特别宽的文字图层会让整张场景退回预览图。创意工坊 3346715292、3361965869、3492627662、3830665420 现在可实时渲染。
- 场景壁纸的木偶（puppet）支持骨骼物理：头发、尾巴、草叶等随动画和图层移动甩动、回弹或被重力拉下，按 Wallpaper Engine 的规则计算。场景脚本也能读写骨骼位置并给骨骼施加冲量，比如拖动角色后松手弹回。测试场景与真实壁纸的骨骼矩阵逐帧对照过它的输出。创意工坊 2345214324、3359451610、3426865175 现在可实时渲染。
- 场景壁纸的场景脚本能在运行中给木偶（puppet）与 3D 模型新建、删除动画层，也能播放只播一次、播完自动移除的动作（`createAnimationLayer` / `playSingleAnimation` / `destroyAnimationLayer`），规则照 Wallpaper Engine 实测。创意工坊 2887099508 的点书翻页用的就是它。
- 场景壁纸的木偶（puppet）支持动画驱动的绘制顺序：部件之间的前后遮挡随动画变化，眼睛等带裁切遮罩的部位跟着按新顺序遮罩，规则照 Wallpaper Engine 实测。创意工坊 3577990983、3841310696 现在可实时渲染。
- 场景壁纸的粒子能落在另一个图层的画面上（Wallpaper Engine 的「图层图像」发射器）：粒子只在那个图层不透明的地方出生、可带上那里的颜色，图层移动时跟着走。myprojects 3834803915（战锤 40k 雨景，雨水溅在人物身上）现在可实时渲染；开场头几帧水花会比 Wallpaper Engine 晚一点出现。
- 场景壁纸的场景脚本能按名字查木偶（puppet）的骨骼，读写骨骼的局部位置、旋转与变换（`getBoneIndex` / `getBoneParentIndex` / `getLocalBoneTransform` 等），写入当帧生效，规则照 Wallpaper Engine 实测。myprojects 3820240793（呼吸与摆头的新娘）现在可实时渲染。
- 新增应用日志：运行日志分级并按天保存到数据目录下的 `logs` 文件夹（保留 14 天），工具箱新增「查看日志」，可按级别、前端 / 后端、模块和关键字筛选，实时滚动，支持复制与打开日志目录。Web 版仅 super 模式可用。

- 壁纸设置新增「Wallpaper Engine 目录」：留空时自动查找（Steam 库，或从已导入的壁纸往上找）并写入，也可以手动指定。没有 Steam 版 WPE 时，把 `assets` 等资源复制到本机就能让场景壁纸读到内置资源，做法见文档「Wallpaper Engine 壁纸」。
- Wallpaper Engine 壁纸现在也支持 macOS 和 Linux：可以导入并在图库预览、应用背景里运行网页与场景壁纸，macOS 还可在窗口模式设为桌面壁纸；音频可视化三个桌面平台都可用（macOS 14.2 起，Linux 需要 PipeWire），媒体集成三个桌面平台都可用，桌面鼠标转发仍只在 Windows 与 macOS，Linux 暂不能设为桌面壁纸。Android 与 Web 版不提供。
- macOS 上 Wallpaper Engine 壁纸的音频可视化可用（macOS 14.2 起）：声明了处理音频的网页与场景壁纸，频谱条、随音乐跳动的光圈、音频粒子等会跟着电脑正在播放的声音变化，和 Windows 一样。第一次显示这类壁纸时系统会询问是否允许 Kabegame 录制系统音频；声音只在本机分析，不录制、不上传。
- Linux 上 Wallpaper Engine 壁纸的音频可视化可用：声明了处理音频的网页与场景壁纸，频谱条、随音乐跳动的光圈、音频粒子等会跟着电脑正在播放的声音变化。需要系统的声音服务是 PipeWire（近年主流发行版的默认；Ubuntu 22.04 默认的 PulseAudio 不支持，频谱保持不动）。显示这类壁纸期间 KDE Plasma 托盘会出现麦克风图标：Plasma 把读取系统声音也算作录音，Kabegame 并不使用麦克风，声音只在本机分析，不录制、不上传。没有声音时不会让声卡保持唤醒。
- 「壁纸」导入现在会带上 Wallpaper Engine 里显示的全部标签：除作者声明的题材外，还有音频响应、可自定义的、视频纹理、年龄分级等（不含分辨率），并按题材、年龄分级、特性分到 `WPE` 下的子目录，名称跟随导入时的界面语言。
- 「壁纸」导入支持 Wallpaper Engine 网页壁纸：原地引用壁纸目录；预览以主屏比例的画布运行页面并可交互，也可在窗口模式设为桌面壁纸，应用背景同样实时显示（静音）。设置里的「壁纸音量」（原「视频壁纸音量」）对网页壁纸同样生效。
- 桌面网页壁纸改为像 Wallpaper Engine 一样以 `file://` 直接加载壁纸目录：依赖读取同目录数据文件的壁纸（如歌单、字幕类）现在能完整运行；文件访问只对壁纸窗口开启，且只能读当前壁纸目录内的文件。Windows 上桌面的鼠标移动与左键点击会转发给网页壁纸（不拦截桌面本身的点击，桌面框选不受影响）。预览网页壁纸时，鼠标移到画布左右边缘中段即可唤出切换箭头。预览网页壁纸时右键菜单无法弹出（右键会被壁纸页面接收），菜单里的操作改为按原顺序排在底部工具条里。
- 网页壁纸可读取作者默认属性与界面语言：桌面壁纸与图库预览里的 Wallpaper Engine 网页壁纸会在加载完成后收到 `project.json` 里作者设定的属性值，以及当前界面语言（切换语言后页面随之更新）；依赖这些属性才开始绘制的壁纸现在能正常显示。帧率见「帧率」设置一条。属性按 Wallpaper Engine 的顺序（按名字排序）交给页面；用单页路由的网页壁纸（如自带的 CORSAIR Collection）切换页面时不再因为改不了地址而报错，以前这类壁纸只显示预览图、切换场景也没有反应。
- 画廊、画册、任务和畅游的工具条右侧 ⋯ 菜单新增「收藏的视图」：把当前的过滤和排序存成一条，可以起名字（不起就用路径作名字，名字不能重复），以后点一下就切回去。列表按最近使用排序；在菜单里来回切换不会打乱顺序，下次打开菜单时才把最后用的那条排到最前。所有画册共用一份收藏，所有任务、所有网站也各共用一份。行尾的编辑按钮可以改名，或用当前视图更新这条收藏（先预览哪些条件是新增的、哪些会被移除，确定后才保存）；叉号移出收藏，需要确认。正在轮播的那条带轮播标记。收藏保存在本机。
- 设置页壁纸分区新增「显示器布局」（目前仅 macOS）：按系统里的排布画出接着的每块显示器及其名字、分辨率，插拔显示器、改排布后约一两秒内自动更新。壁纸设置的各项按「全局设置 → 显示器 → 轮播路径、当前壁纸、显示方式与过渡」重新排了顺序，「壁纸模式」移到了前面。
- 新增按颜色排序：画廊、画册、任务和畅游的排序菜单多了「颜色」，点开选一个色块（红橙黄绿青蓝紫粉棕黑白灰），画面最接近这个颜色的排在前面；也可以点「＋」自己取色，直接按它排序，或把常用的颜色保存下来（最多 24 个，保存后排序更快）。Wallpaper Engine 壁纸与视频同样参与。
- 图片详情的「基本信息」里新增代表色：一条按占比分段的色带，鼠标停在上面显示色值与百分比，点其中一段可以让当前页面按这个颜色排序（过滤条件不变）。升级后会在后台为已有图片计算一次代表色，期间可正常使用，还没算到的图片按颜色排序时暂时排在最后。
- 整理新增「重新计算代表色」：为整理范围内的每张图片重新计算代表色（换了文件、当初没算出来，或者想按新的算法更新时用），算不出来的保留原来的代表色；进度和完成提示里会显示更新了多少张。
- 图库预览里的网页与场景壁纸，鼠标移到画面外的空白处、详情栏，甚至应用窗口外时，景物（视差、跟随鼠标的粒子等）也继续跟着鼠标，停在画面边缘；在画面上点击照常传给壁纸。Linux 上仍只在壁纸画面上跟随。
- 图库预览里的网页与场景壁纸可以和图片一样放大：Ctrl+滚轮或工具条缩放，放大后用滚轮、左键或中键拖动画面；按住 Ctrl 用左键时只和壁纸交互、画面不动（拖到一半松开 Ctrl 会接着拖）。放大后场景画面跟着变清楚。放大时「设为壁纸封面」截的是看得见的那一块，可以借此挑封面的取景。
- 图库预览里的视频（含 Wallpaper Engine 视频壁纸）也可以和图片一样放大：Ctrl+滚轮，或把鼠标停在视频控制条新增的放大按钮上拖出现的滑块（点一下按钮回到原大小）；放大后用滚轮或鼠标拖动画面，拖动不会暂停视频，单击照常播放 / 暂停。双击视频不再切换全屏，全屏用控制条上的按钮。
- 场景壁纸支持点光与平行光的实时阴影：3D 模型按 Wallpaper Engine 的方式投下影子，镂空的树叶、棋盘格等贴图投出带孔的影子，随风摆动的植物影子也跟着动；设置页壁纸分区新增「场景阴影」（跟随 WPE / 关闭 / 低 / 中 / 高 / 超高，默认跟随 Wallpaper Engine 自己的阴影设置），各档的画面与 Wallpaper Engine 逐像素对照过（相差不超过 1/255）。聚光灯的阴影暂不支持。
- 场景壁纸支持体积光（光线穿过空气形成的光柱、光晕）：点光与聚光灯按 Wallpaper Engine 的方式画出体积光，被模型挡住的部分照样留出阴影，镜头进到光里时也一样；画质默认跟随 Wallpaper Engine 自己的体积光设置，也可以在「壁纸设置」与预览的「预览设置」里选低 / 中 / 高 / 超高 / 关闭，各档的画面与 Wallpaper Engine 逐像素对照过（相差不超过 1/255）。创意工坊里只差体积光的场景（如 3837478759）现在可以实时渲染。
- 场景壁纸支持距离雾与高度雾：3D 模型、粒子、图片与文字图层都按 Wallpaper Engine 的方式蒙上雾色，雾的颜色、远近与浓度属性改了即时生效；画面与 Wallpaper Engine 逐像素对照过（相差不超过 1/255）。只差雾的创意工坊场景（如 3115845558）现在可以实时渲染。
- 场景壁纸的灯可以挂在会动的物体上、亮度和颜色随动画与脚本变化（如按住鼠标时太阳变亮），灯的移动与开关即时生效；带灯光的创意工坊场景（如 3706286085）现在可以实时渲染。
- 「场景反射」开着时，3D 模型上光滑、金属材质的屏幕反射（映出周围画面的模糊倒影）也会实时画出，以前这类场景在反射开时只能显示封面；模糊程度逐级对照过 Wallpaper Engine，测试场景与 3453730450 里的反光模型和它的输出逐像素一致。
- 透视视角的 3D 场景里的文字会被前面的模型挡住，带子图层的组合层、透明物体排序下的体积光也按 Wallpaper Engine 的方式画出；创意工坊 3453730450（《玉盘 /Moon》）、3509243656（三体实时演算）现在可实时渲染，测试场景与 3453730450 的复制场景和它的输出逐像素一致。
- 场景壁纸的聚光灯（射灯）也能投下影子：被照亮的物体在锥形光斑里留下阴影，跟随「场景阴影」设置的档位；规则逐项对照过 Wallpaper Engine，测试场景与它的输出逐像素一致。创意工坊 3455121165（Solar system 太阳系）现在可实时渲染。
- 场景壁纸里受灯光照亮（或带反射）的图片图层，叠了效果、混合模式或雾时，灯光改在效果之前算，效果处理的是已经打过光的画面，同 Wallpaper Engine；测试场景与它的输出逐像素一致。
- 带骨骼动画的人物图层（puppet）受灯光照亮又叠了效果时，也按 Wallpaper Engine 的方式先跟着动作打光、再做效果；创意工坊 2515018199（Knight Artorias）现在可实时渲染，复制场景与它的输出几乎逐像素一致。
- 场景壁纸的聚光灯支持投影图样（cookie）：灯光像透过灯罩一样把图样投到模型、图片与粒子上，带体积光的聚光灯光柱里也带着图样和被遮挡的影子；不写图样时用 Wallpaper Engine 自带的缺省图样，多盏带图样的灯同 Wallpaper Engine 一样共用排在最后那盏的图样。测试场景与它的输出逐像素一致（相差不超过 1/255），创意工坊 3839619935 现在可实时渲染。
- 场景壁纸新增「强制渲染」设置：壁纸用到暂不支持的特性时也照常渲染，不再只显示封面（画面可能缺东西或和 Wallpaper Engine 不一致，打开时会先提醒）。桌面在设置页「壁纸设置」里开，图库预览与应用背景按每张壁纸在预览右侧的设置里开；预览里显示不了的场景，在底部原因下面点「我就要看」也能直接打开，开着时预览标题旁会标出「强制渲染」；桌面上显示不了时会提示去壁纸设置里打开；应用背景里的场景壁纸总是强制渲染。打开或关掉后场景会立刻回到加载状态、从头重新加载。

- 场景壁纸的文字支持描边、模糊和投影（Wallpaper Engine 的 MSDF 文字）：字形距离场用和 Wallpaper Engine 相同的 msdfgen 版本与参数生成，描边粗细、颜色、模糊与投影的大小、偏移、不透明度按它的规则取值，改这些属性即时生效；文字的背景色由脚本按时间变化时也照常变。测试场景和 4 张创意工坊壁纸（3833971732、3816870245、3829268059、3593919489）的文字与 Wallpaper Engine 逐像素一致，这 4 张现在可以实时渲染。MSDF 文字里的彩色表情暂不显示（语料里没有用到）。
- 场景壁纸支持脚本的 `resizeScreen` 回调：壁纸的分辨率变了（换分辨率、改系统缩放）时通知场景脚本重新排版，同 Wallpaper Engine；创意工坊 3838286359（Liquid Glass Now Playing）现在可实时渲染。
- 场景壁纸支持把带子图层的组合层当遮罩被别的图层引用：组里的子图层（如跟着鼠标走的斜线）画进遮罩，组隐藏时遮罩里只剩组自己的底，同 Wallpaper Engine，测试场景与它的输出逐像素一致。创意工坊 3811403844（【绝区零】佩洛伊斯-铃）现在可实时渲染。
- 场景壁纸支持脚本自己生成的 3D 网格（Wallpaper Engine 的 `IModelData`）：把 Live2D 等动画运行时写进场景脚本的移植壁纸现在能实时渲染，部件在第一帧就全部出现，脚本每帧改的顶点当帧生效；画面与 Wallpaper Engine 逐像素对照过。创意工坊 3834692798（StellaSora - Karin）现在可实时渲染，本机全部场景都不再有不支持项。Wallpaper Engine 里这类部件用到的「正片叠底」效果会画成半透明的黑色，这里按作者的本意显示；它的几处脚本接口缺陷（如销毁模型数据时传对象无效）也没有照搬。
- 场景壁纸里挂进「组合层」的 3D 模型现在照 Wallpaper Engine 画出来：创意工坊 3816948983（林间锦鲤）的水面不再偏亮偏青、边缘也没有拉丝了。
- 场景壁纸组合层里的图片图层，传给着色器的模型矩阵与视图投影改成和 Wallpaper Engine 一样的组内坐标（本机的作品画面不变，影响的是在组合层里读这两个矩阵的着色器）。
- 场景壁纸组合层里的粒子，组合层带前后倾斜时朝向和 Wallpaper Engine 一样跟着组合层一起斜（以前总是正对屏幕；本机的作品里没有放在组合层里的粒子，画面不变）。
- GNOME 上的插件模式：切换前检查 GNOME 版本（支持 GNOME 42–51，版本太旧时提示升级系统）；没有检测到 Kabegame 的 GNOME Shell 扩展时可以直接安装，装完注销并重新登录即可切换。插件模式下扩展不在了（被关掉、GNOME Shell 重启）会自动切回原生模式并提示。
### Optimized
- 脚本很多的场景壁纸不再卡成幻灯片：脚本按名字找图层、把同样的值写回图层时不再做大量重复计算，创意工坊 3662790108（Live Solar System）的预览从约 2 帧每秒提到 30 帧上限。
- 场景壁纸改为按显示分辨率渲染（和 Wallpaper Engine 一样）：分辨率小的场景（如自带的 Dino Run）在图库预览、桌面和应用背景上不再模糊，文字与线条清晰；预览里放大后按放大后的分辨率重画，越放大越清楚（主窗口里最多按 4K 画，再放大只是拉伸）；「适应」「居中」显示方式下，留白处和 Wallpaper Engine 一样能看到超出场景范围的内容；调整窗口大小、开关侧栏或全屏时场景接着播放，不再重新加载。「平铺」显示方式不变。
- 桌面版视频（含 Wallpaper Engine 视频壁纸）的缩略图改为第一帧静图，图库网格更轻；鼠标悬浮时直接播放原视频，不用打开就能看。升级后已有视频的缩略图会在后台自动重做，旧的预览短片随之删除。Android 仍用动图缩略图。
- 桌面版预览视频（含 Wallpaper Engine 视频壁纸）时，右键菜单新增「设为壁纸封面」：把当前播放到的那一帧设为这个视频在图库里的缩略图。
- 场景壁纸改颜色、透明度、位置、亮度与滑块类属性时即时生效，不再整场重新加载；按属性条件显示 / 隐藏的图层也能正确切换。
- 场景壁纸开关图层效果、泛光，以及改背景色等属性时也即时生效，不再重新加载。
- 场景壁纸图层的贴图采样位置与 Wallpaper Engine 对齐，放大低分辨率贴图时不再有亚像素偏移。
- 桌面版窗口标题随当前内容显示预览图片名、画册名及畅游 / 爬虫页面标题，并跟随界面语言切换；Web 版标签页标题同步采用「内容 - 页面 - Kabegame」格式。
- 窗口模式桌面壁纸（含 Windows 网页壁纸）卡死或与后台失联时，会在约 30~40 秒内自动重新加载，不再一直停在旧画面或白屏；壁纸被其它窗口遮住时不会误判。
- 桌面版（Windows / macOS / Linux）图库、预览与窗口壁纸里的图片、缩略图和视频改由内置浏览器直接读取本地文件，不再经过应用内的本地 HTTP 服务；桌面本地 HTTP 文件服务不再监听端口，复制兜底改用 `file://`。插件文档和配图由应用内命令读取并缓存。插件详情页（插件模板）改在更严格的隔离环境里运行：模板不能再直接发网络请求或访问主界面，模板里写的远程图片照常显示。
- Windows 桌面版从图库把图片或视频拖到资源管理器、Word、聊天软件等程序时，得到的是库内原文件（不再是缩略图或需要下载的地址）；三个桌面平台的拖出都只复制，不会把库内文件移走。
- Windows 安装程序在最后阶段不再一个接一个地闪出大量黑色命令行窗口：搬运 CEF 运行时、DLL 与设置目录图标属性改用安装程序内置指令完成。
- 桌面端界面卡死后的自动恢复更快：页面无响应约 6 秒（原约 16 秒）即自动重新加载。
- 按视频筛选和视频计数在大图库下明显更快；应用启动时会刷新数据库的查询统计，启动页显示「正在优化数据库」，图库越大这一步越久。
- 场景壁纸里的视频改由应用自己解码，不再经过浏览器的视频播放器：视频和场景同时开始（以前视频会比场景早放零点几秒到一秒多）、循环时没有停顿，长视频加载时不再整段写进磁盘缓存；标清视频（包括属性面板里选的视频）不再整体偏色，场景里标了标清色彩信息的视频颜色和 Wallpaper Engine 一致。和 Wallpaper Engine 相比只在颜色上下剧烈变化的边缘还有细微差别。
- 场景壁纸的脚本运行中新建图层（`createLayer`）不再整场重新加载：建过同样配置的对象再建时当帧出现（如反复建删的粒子、克隆已有图层），第一次出现的配置在后台单独编译、下一帧装上，期间画面不停、脚本照常跑；加载时脚本在 `init` 里建的图层也不再让场景多编译一次。改属性后克隆出来的对象和模板一起变，克隆的关键帧从头播，粒子按作者设的预热时间预热，和 Wallpaper Engine 一致。
- 场景壁纸运行中新建的图层用到暂不支持的特性时，场景不再整个退回预览图：只是那个图层不画，其余照常，并由看板娘提示一次「用到了暂不支持的特性：…」（桌面壁纸窗口的提示也显示在主窗口里）。
- 场景壁纸运行中改要重新编译才生效的单个图层设置（脚本换文本图层的字体、属性面板改图层的 `size` / `colorBlendMode`、打开用到暂不支持特性的 effect）只重编那一个图层，不再整场重新加载：期间画面不停，别的图层的粒子、动画、声音接着跑；换上时它自己的关键帧从原来的进度接着播，没改到粒子定义时粒子也不重来；连着改几次只以最后一次为准。
- 场景壁纸的脚本运行中改图层结构（把图层挂进 / 移出组合层、挂到骨骼上、删掉组合层）不再整场重新加载，改动当帧生效，和 Wallpaper Engine 一致：挂进组的图层当帧画进组里、空的组合层挂上子层当帧变成组、删掉组后剩下的子层当帧回到顶层；期间别的图层的粒子、动画不受影响。
- Linux 上用 NVIDIA 显卡时，场景壁纸里的视频改用显卡硬件解码（以前一律软件解码，4K 视频很吃 CPU）：deb 包推荐安装 `nvidia-vaapi-driver`（用 apt 安装时会自动带上），装了它 Kabegame 就会打开 NVIDIA 显卡的硬解。驱动出问题时可以设环境变量 `KABEGAME_CEF_VAAPI_NVIDIA=0` 关掉。

### Changed
- Linux 上图库预览里的网页 / 场景壁纸和 Windows、macOS 一样了：鼠标在预览外也会让壁纸跟着（贴在边上）、放大后能拖动平移、Ctrl+左键与壁纸交互，点过壁纸后 Esc 与方向键照常；插件模式下鼠标在主窗口上时桌面壁纸也跟着移动。
- KDE Plasma 6 上的「插件模式」不用再单独装壁纸插件：Kabegame 自带插件，切到插件模式时自动装好，以后随 Kabegame 更新自动升级、不用重启桌面；卸载 Kabegame（deb）时插件一并删掉，桌面换回原来的壁纸。

- 下线「画册盘（虚拟盘）」：不再把图库挂载成本地磁盘或目录（Windows 的 Dokan、macOS 的 macFUSE、Linux 的 FUSE 一并移除），设置「高级」里的画册盘开关与挂载点、画册页顶栏和画册右键菜单里的「打开虚拟盘」都已移除，升级后旧的画册盘设置会自动清理。下线的原因：图库本身的浏览、筛选、排序与画册组织已经够用；想在应用之外按条件找图、取图，可以开启「设置 → 高级」里的 Web 服务器，它提供的画廊查询比文件系统目录视图表达力强得多；而虚拟盘要求安装 Dokan / macFUSE / FUSE 这类系统级驱动，带来的安装与分发负担和它能提供的只读目录视图不成比例。如果你此前专为 Kabegame 安装过 Dokan（Windows）或 macFUSE（macOS），现在可以自行卸载。

## 插件开发侧

### Changed
- 插件私有数据（`pluginData` / `setPluginData`、详情模板的 `__bridge.getPluginData`）的顶层键 `__private` 归宿主保留：读取时不返回，插件写入这个键会被忽略，原有内容保留。
- kabegame-server（0.3.0）：`x-wpe/*` 行改为先请求 `/file/<目录>` 取文件清单，再经 SDK 的 `downloadWpeWallpaper` 整目录复制；`engines.kabegame` 提到 `>=4.7.0`。
- 图片详情的插件模板（`description.ejs`）iframe 不再与应用同源（去掉 `allow-same-origin`），并在文档最前带内层 CSP（`connect-src 'none'`、`frame-src about:` 等）：模板里直接 `fetch` / XHR / WebSocket、`<link>` 外链样式、远程字体、嵌套 http(s) 或 `file:` iframe 都会被拒，网络请求一律经 `__bridge.fetch`；`<img>`、CSS 背景等元素级远程图片与嵌套 `srcdoc` iframe 不受影响；`window.parent`、`localStorage` 不可访问（跨次缓存用 `__bridge.getCache` / `setCache`）。

### Added
- `Kabegame.downloadImage(vfsPath, { relocate: true })`（V8 与 WebView）：`url` 是 `Kabegame.fs` 的虚拟路径时，把这个文件或目录移进输出目录而不是复制一份，库里已有相同内容时直接删除，调用之后该路径不再存在；只对虚拟路径生效。源必须在可写挂载上，不能是挂载根，也不能包含符号链接。虚拟路径可以是一个 Wallpaper Engine 壁纸目录（必须带 `relocate: true`，仅桌面端），整个目录作为一张壁纸入库，metadata 固定是它自己的 `project.json`（`metadata` / `metadata_id` 被忽略）。`@kabegame/types` 同步新增 `KabegameDownloadImageOptions.relocate`。
- `@kabegame/plugin-sdk` 新增 `downloadWpeWallpaper`（`@kabegame/plugin-sdk/wpe`）：按文件清单把壁纸目录逐个文件 `fetchToFile` 到任务 VFS 的 `tmp/wpe`，再整目录提交；支持单文件重试、大小校验、逐文件回调与空跑，并清理 12 小时以上的残留。
- 桌面端 Web 服务器的 `/file/<目录路径>` 对 Wallpaper Engine 壁纸返回文件清单 `{ type, files: [{ path, size }] }`，`/file/<目录路径>/<相对路径>` 返回目录里的文件（越出目录的路径 404）。
- `kabegame-cli plugin run` 新增 `--freeze-template`：把本次运行插件的 `description.ejs` 冻结进每行 metadata（新列 `metadata.template`），详情面板优先用它渲染。`--id` 测试 id 没有安装，过去它下载的图片只能看原始键值，现在也能直接在应用里调试模板。插件模板与冻结模板并行获取，冻结模板非空时覆盖插件模板。

### Fixed
- `kabegame-cli plugin new` 模板的 rspack 输出路径改用 `fileURLToPath`：原来的 `URL.pathname` 在 Windows 上是 `/D:/...` 形式，rspack 产物落不到插件的 `dist/`，打包时报 `main 脚本不存在`（模板编译期内嵌，重新构建 CLI 后生效）。

- 构建缓存不再被命令之间反复掀翻（原来「改完代码 → `check` → `dev`」每一轮都要把 `kabegame-core` 与 `kabegame` 全量重编、`kabegame.exe` 与 `kabegame-cef-helper` 全量重链）。cargo 把 build script 读到的环境变量**值**记进 fingerprint，值一变就 `EnvVarChanged` → build script 重跑 → 依赖它的整个 crate 连同全部 bin 重编；而各命令注入的环境本来就不同。三处改动：产物目录按命令隔离，`dev` / `start` / `check` / `test` 用 `target-dev/`、`b` 仍用 `target/`（新增 `scripts/target-dir.ts`，在 `run.ts` 的第一个 import 位置注入，显式设了 `CARGO_TARGET_DIR` 时一律以它为准；`.mcp.json` 给 `kabegame-dev` MCP 配上同一个目录）；`--data` 默认值统一成「带 `--release` 为 prod，否则 dev」（原来 `check` / `test` / `start` 默认 prod，与 `dev` 冲突）；`tauri.conf.json` / `capabilities/main.json` / `index.html` 三个 handlebars 生成文件改成内容有变化才写（`utils.ts` 新增 `writeFileIfChanged`——cargo 判新鲜度比的是 mtime 而不是内容，tauri-build 又对 `tauri.conf.json` 发 `cargo:rerun-if-changed`，无条件重写会让整个 `kabegame` crate 每次重编）。VSCode 的 rust-analyzer 也要隔离（`rust-analyzer.cargo.targetDir`，它后台跑 `cargo check` 时环境里没有 `CEF_PATH` / `FFMPEG_*` / `KABEGAME_DATA`），但 `.vscode/` 被 gitignore，需各自本地配。排查手法与传导链见 `scripts/AGENTS.md`「产物目录隔离」。macOS / Linux 上 dev 跑在 `target-dev/` 里要靠 tauri 补丁 20（`tauri-utils` 的 `resource_dir` 也认 `CARGO_TARGET_DIR` 指的产物目录）：上游只认名叫 `target` 的目录，否则把 exe 当安装包，macOS 一启动就因找不到 resource 目录 panic，Linux 静默落到 `/usr/lib/Kabegame`、场景宿主报 `scene host is not built`。
- release 构建的优化配置重新生效：`[profile.release]` 原先写在 `src-tauri/kabegame/Cargo.toml`，而 cargo 只认工作区根的 profile（非根包的只会打一行 `profiles for the non root package will be ignored`），所以 `opt-level` / `debug` / `strip` / `overflow-checks` / `rpath` 一直是 cargo 默认值；现在搬到根 `Cargo.toml`，其中 `strip = true` 是唯一行为变化（产物体积变小，Linux / macOS 的 panic backtrace 不再带符号名）。两处刻意不照搬：`panic = "abort"` 不要——`crawler/task_scheduler`、`providers/sql_executor` 与 `init_heavy_globals` 都靠 `catch_unwind` 把 panic 关在局部，abort 会让一个插件 panic 带走整个进程；`lto = "thin"` 与 `codegen-units = 1` 改由 `ReleasePlugin` 在 `deno task b --release`（发版，CI 用的就是它）时经 `CARGO_PROFILE_RELEASE_*` 打开，日常 `deno task b`（主应用恒 release 构建）不付这几倍的链接时间。`codegen-units` 原先走 RUSTFLAGS，一并改成 profile 环境变量——RUSTFLAGS 里的 `-C lto` 会和 cargo 给依赖传的 `-C embed-bitcode=no` 互斥，直接编译失败。
- `build:wpefont` 在编译前预检 wasm 链接器（`clang -Wl,--version`）：缺链接器时不再编完全部单元才在链接时报 `posix_spawn failed`，而是直接报出 clang 要找的可执行文件（Ubuntu 的 clang-N 找 `wasm-ld-N`）与安装命令。
