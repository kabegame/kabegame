# v4.5.2 changelog

## 用户侧

### Added
- 任务列表顶部新增搜索框，输入插件名称或插件 ID 即可筛选出对应任务。
- 桌面端视频预览支持按空格键播放/暂停，按 `Command/Ctrl + ←/→` 快退/快进 5 秒。
- 插件商店现在会在启动时刷新并每 4 小时自动更新；桌面侧栏与紧凑端底部的「插件」图标会显示可更新插件数量，插件页对应商店源的 tab 上也会显示该源可更新的数量。
- 运行配置卡片的「更多」菜单新增「复制为推荐配置 JSON」，复制内容可直接保存为插件 `configs/` 下的推荐配置文件；「更多」菜单改为下拉选择框样式。
- Android 支持畅游：可在独立页面打开站点并登录，自动保存 Cookie 供需要登录的插件复用；插件接口 `Kabegame.cefUserAgent()` 在 Android 上改为返回系统 WebView 的 User-Agent，与 Cookie 配对后 Cloudflare 站点不再 403。
- Android 畅游支持一键下载与页面内下载：内容页改为 Tauri webview，与桌面共用注入脚本和下载命令；下载前自动补 Cookie / User-Agent / Referer，图片和视频直接进入该站点的畅游记录。页面自发下载的 zip 等压缩包只提示不支持、不下载（解压交给各插件）。

### Optimized
- 将 v8 fetch 请求超时上线提高到5分钟

### Changed
- Android 在用户启动首个任务时立即请求通知权限，不再等任务状态刷新后才弹出权限确认；拒绝权限也不会阻止任务启动。
- Android 紧凑布局下各页面的公共标题栏统一贴齐状态栏安全区下缘与屏幕左右边缘，不再受页面内容区外围留白限制；平板横屏等非紧凑布局继续使用桌面 gutter。
- Android 畅游首页移除页面内容区的外围留白，让正文与标题栏使用一致的全宽布局，并让搜索框与下方记录卡片左右对齐。
- Android 独立畅游窗口顶部的返回、前进、刷新、外部打开与关闭按钮改为图标自然宽度加少量水平留白，减少图标间的空隙并给地址栏留出更多宽度。
- Android 畅游页的插件快选改为图标按钮，点击后在弹窗中选择插件，不再让插件名与 URL 输入框抢占同一行宽度；桌面端保持原有下拉选择器。
- Android 畅游顶部导航栏改为原生控件（后退 / 前进 / 刷新 / 地址栏 / 一键下载 / 在浏览器打开 / 关闭），地址与一键下载运行态由 Kotlin 直接操作内容页，不再经过 `surf-navbar.html`。图标沿用桌面导航栏的同一套线条图标，按压有圆角反馈，一键下载运行中与桌面一样显示旋转弧线。
- Android 畅游内容页的 IPC 改为 `addWebMessageListener` 并只接收主框架消息，第三方 iframe 无法再冒用主页面身份；设备不支持该特性时关闭 IPC（只能浏览，不能一键下载）。
- Android 插件详情标题栏的安装、更新与重装操作改为图标按钮，并移除标题栏内重复的“已安装”状态，给插件标题留出更多空间；安装与卸载确认框接入统一返回栈，安装包大小正确显示，安装成功后停留在当前商店详情，卸载成功只切换一次到插件列表；桌面端保持原样。
- 本地原图、缩略图与浏览器兼容副本统一使用 `/file/{*path}`、`/thumbnail/{*path}`、`/compatible/{*path}`，不再把绝对路径放在 `?path=`；独立 `/download` 端点已移除。Windows 拖出文件直接复用当前实际加载的媒体地址，原图缺失并回退到缩略图或兼容副本时仍可拖出。
- Web 版 RPC 请求地址带上方法名（`/rpc/{method}`），在浏览器开发者工具中可直接按接口过滤；服务端保留旧 `/rpc` 入口兼容现有客户端。
- Android 收集表单的插件选择入口改用与桌面一致的下拉框组件展示当前值，插件与输出画册都通过弹窗选择，不再以全屏覆盖层选择输出画册；插件配置中的单选字段也改用项目下拉组件，不再使用 Vant 列表，可搜索下拉首次展开时不再自动聚焦或弹出软键盘。
- 插件配置项都可以随时清空（插件收到空值），必填项只在启动任务时校验，保存插件默认配置时可以留空。
- 插件页当前所在的商店 tab 记录在地址栏（`?tab=`），从插件详情返回时停留在原商店 tab，商店列表与图标不再重新加载。
- 画册选择下拉框不再显示分区之间的分割横线。
- 插件页的快捷预览改为右键卡片打开，不再鼠标悬停自动弹出；插件没有 banner 图时预览里不再显示示例图区域。已安装 tab 的卡片不再显示更新红点（在那里点开无法更新），更新提示统一到商店源 tab。
- 失败图片按钮与插件导航的数量角标统一为同一种样式。
- 任务列表中正在运行的任务不能直接删除，需要先停止任务；运行中的删除按钮和右键「删除任务」会置灰。
- 任务列表进度条旁的停止叉号不再弹出确认对话框，改为在叉号下方弹出「停止任务？」小确认框；右键菜单「停止任务」仍用确认对话框。
- Android 画廊的过滤与排序不再收在右上角菜单里，改为和桌面一样在标题下方显示一排 chip；点击 chip 弹出对话框，内容与桌面下拉面板相同，返回键可关闭。画册、任务与畅游详情在 Android 上也有了同样的过滤 chip。
- 文档
    - readme更显示介绍而非简单的声明
    - 日文、韩文和英文 README 同步重写为与中文版逐行同构的产品入口结构（181 行）。
    - 主站文档同步，去掉过时内容
    - 畅游指南按当前 dev 重写，补充一键下载、冻结网页、Cookie 复用和站点下载图片管理，并用带 `-annotated` 标识的 Wallhaven 实机截图精简操作说明。
    - 画册指南用 9 张带短标签和箭头的 dev 实机截图替代大段入口说明，突出标签自动归类、本地文件夹同步以及「移除关系 / 删除文件」的区别。
    - 任务指南补齐「等待剩余下载」收尾状态、逐任务下载并发、任务详情、创建与停止确认流程，并用 5 张带标注的 dev 实机截图指出关键状态与操作位置。
    - README 与畅游指南加入畅游下载流式视频的实机截图（指南版带标注），说明捕获进度面板与流式视频的限制；去掉文档中「Linux 畅游受 WebKit 限制不能下载」的过时说法。

### Fixed
- Android 分享图片不再报「文件不存在」：MediaStore 中的图片（`content://` 地址）现在直接交给系统分享面板，并按系统登记的类型分享，目标应用能正确识别为图片/视频。
- Android 插件标签提示改为点击后保持显示，再次点击标签或点击外部才关闭，不再在手指抬起时立刻消失；桌面端仍使用悬停提示。
- Android 点击插件详情中的 `baseUrl` 等外部链接时，不再绕过打开方式设置直接跳转系统浏览器；现在与桌面端一样，可选择在畅游中打开或使用系统浏览器。选择框及其它全局模态单例统一移到主布局容器外，打开时不再把插件 Doc 挤到下方造成内容区空白。
- Web 版会把浏览器兼容副本与壁纸兼容副本路径一并改写为 CDN URL；线上 `compatibles` 目录接入 OSS，不再向接口返回服务器本地路径或请求不存在的 `/compatible`。
- 插件请求（`fetch`、`to()`、下载）不再被 Cloudflare 当作机器人拦截：此前走 HTTP/1.1 时请求头名全部是小写，会直接触发挑战（anime-pictures 等站点返回 403）。现在桌面端也能协商 HTTP/2，退回 HTTP/1.1 时请求头名改为首字母大写，与浏览器一致。
- 不兼容当前应用版本的商店插件不再显示更新提示，导入或安装时后端也会在写入插件目录前拒绝。
- 畅游右键下载长视频不再 16 倍速从头反复重放、最后超时失败，也不再因混入多档清晰度出现流错位或「找不到流」；改为正常倍速跳着补拉并只拼同一清晰度，页面右下角会显示每路流的捕获进度。刚开始播放就右键下载也不会再误报「无法全缓冲直播流」。YouTube 等音视频分属 WebM / MP4 的站点不再在合并时报 `write mux header … Error(-22)`。YouTube 等启用 Trusted Types 的站点上，视频右键菜单恢复显示。YouTube 下载偶发「视频补拉停滞超时」（视频明明在播）也已修复：不再反复跳回缺口打断正在下载的分片。
- 桌面宽屏标题栏补上「管理源」入口，可编辑商店源名称与地址。
- Linux 畅游帮助弹窗不再显示过时的「因 WebKit 限制无法下载」提示（Linux 已改用 CEF，可正常下载）。
- 畅游与 WebView 爬虫窗口里的右键菜单、页内提示和视频捕获面板跟随应用语言显示，不再固定为中文。
- 桌面端插件选择下拉框搜索时同时匹配插件 ID，可直接输入 `pixiv` 等 ID 找到插件。
- 插件配置中「不限」「全部」等空值选项现在能正常显示和选择。
- 源管理弹窗中删除商店源现在会真正删除。
- 修复管理源按钮不显示的问题
- 修复文件夹画册切换为递归同步（或从递归切走）后，画册树中已展开的子画册仍显示旧同步状态、需要手动刷新的问题。
- 修复加入画册、收集输出画册、轮播画册等选择器里标签目录无法展开、选不到目录下标签的问题：点目录行即展开。
- 修复 Android 源管理页商店 tab 中插件名较长时两列网格被撑宽、卡片横向溢出被裁掉的问题。
- 修复 Android 下载进行中按返回键关闭预览时，预览会被重新打开（表现为返回无反应，或预览不可见、吉祥物消失、看起来卡住）的问题。
- 修复 Android 预览过一张图后再点其它图片，打开的仍是上一次那张的问题；从下一页滑回上一页时不再落到倒数第二张。
- 修复 Android 画册页面包屑、过滤 chip 与图片紧贴屏幕左边缘的问题，现在与画廊一样左右各留 20px。

## 插件开发侧

### Added
- 新增变量字段 `required: true` 显式声明必填。没有 `default` 不再隐式等于必填；可选字段不需要再写 `default: ""` / `default: []`。必填只在字段可见时校验，由宿主在创建任务前统一拦截（主应用、CLI、自动任务都会经过）。
- `@kabegame/plugin-sdk` 与 `@kabegame/types` 发布到 npm 并改为 MIT 许可；`kabegame-cli plugin new` 的 V8 模板改为从 npm 安装二者（版本跟随 CLI），仓库外的插件作者生成后可直接 `npm install`。

### Changed
- 插件发出的 HTTP/1.1 请求头名改为首字母大写（如 `user-agent` → `User-Agent`、`x-csrf-token` → `X-Csrf-Token`）；桌面端可协商 HTTP/2 时按 HTTP/2 规范使用小写。头名按 HTTP 规范不区分大小写，正常站点不受影响。
- **Breaking**：`kbConfig` 变量的取值语义重新定义，插件脚本需要能处理 `null` 与 `undefined`：
  - 被 `when` 隐藏的字段**不出现在 config 中**（读到 `undefined`）；
  - 可见但用户未填的字段为 `null`，宿主不再补 `""`、`0`、`[]` 或全 `false` 的 checkbox 对象；
  - 没有 key 时才回落到用户默认配置、再回落到 `default`；用户主动清空带 `default` 的字段得到的是 `null`，不会回落；
  - `boolean` 永不为 `null`，没写 `default` 时为 `false`；
  - checkbox 的值是包含全部 `variable` 的 `{ [variable]: boolean }` 对象，一项都没勾时为 `null`；
  - options 中声明的 `variable: ""` 是合法选项值，选中时原样传 `""`。
- 宿主在创建任务前严格校验变量值，不再静默纠正：字符串类必须非空、list 必须非空、int / float 受 `min` / `max` 约束、options 必须是当前可见的选项、checkbox 键集合必须与声明一致，不合规直接拒绝任务。
- `when` 支持链式传递：被隐藏的字段不能再让依赖它的字段可见。字段级或选项级 `when` 形成依赖环的插件会在打包与安装时被拒绝。
- CLI `plugin run --var`：`key=` 显式清空为 `null`；checkbox 写作 `key=a,b`；options 只接受声明过的 `variable` 或显示名，其余值直接报错。
- `@kabegame/plugin-sdk` 类型：`kbCfgField<K, T, M>` 新增修饰参数，`{ required: true }` 去掉 `null`、`{ when: true }` 让 key 变成可选；`kbCfgCheckbox<V>` 改为 `Record<V, boolean>`，与运行时一致。
- 仓库内插件已全部迁移：删掉多余的空 `default`，给必需输入加上 `required`，并修复把 `null` 拼成字符串 `"null"` 的读取点。第三方插件请检查 `String(x)`、模板字符串插值、`x.trim()` / `x.split()` / `x.length` 和 `Object.entries(checkbox)` 等写法。
- 插件 `package.json` 的 `name` 可写成 `kabegame-plugin-<id>`，应用加载时剥离前缀作为插件 id；`kabegame-cli plugin new <id>` 生成 `kabegame-plugin-<id>/`，`plugin pack` 要求输出 `<id>.kgpg`；官方插件目录同步改名，id 不变，`engines.kabegame` 提到 `>=4.5.2`。

## 开发侧

### Added
- 项目新增 `annotate-ui-screenshots` skill，统一真实界面截图的短标签、箭头、文件命名、目视复核和正文去重流程。

### Changed
- AGENT 约束文档
    - 将顶层命令的参数、构建注意事项和验证指南迁入 `scripts/AGENTS.md`，根规则仅保留命令索引和用途摘要。
    - 将组件库、`packages/` 子仓库和生成型包的维护规则收口到 `packages/AGENTS.md`。
    - 将第三方补丁工作流统一收口到 `third-patches/AGENTS.md`，并明确 CEF 正式补丁序列与构建期临时提交的边界。
- debug ingest 支持 Android：WebView 代理会丢 POST body，Android 端改把事件放进 `event` 查询参数。
- 画册目录页的 `~~/images` 计数不再给标签目录（`label_dir`）出行；前端画册树只等行与子画册数就渲染，图片计数单独到达后再补。
- CEF runtime 适配 Tauri 2.12：同步显示器查询、指定显示器全屏、权限请求与 macOS 启动激活策略等 runtime trait。

- CEF 桌面端的普通 invoke 不再被强制改走 postMessage，恢复上游 `fetch(ipc://)` 主通道，DevTools Network 面板可以看到每次 IPC 的请求与响应内容；二进制写入（畅游 / WebView 爬虫的分块落盘、`Kabegame.fs` 写文件）也改走标准 invoke，删除 runtime 注入的 `__kb_raw_invoke__` 与 `cef-ipc://localhost/raw` 帧化通道。

- 插件新增 `Kabegame.getLang()` 与 SDK `defineI18n`；konachan 插件日志、宿主任务链路日志支持简中、英文、日文、韩文、繁中显示。
