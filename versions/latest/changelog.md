# v4.7.0 changelog

## 用户侧

### Added
- macOS 窗口模式支持多显示器：每块显示器都有壁纸（原来只有主屏）。设置页「显示器模式」可选「各屏复制」（所有显示器同一张，视频只有主屏出声）或「逐屏独立」：点显示器布局图里的一块屏，就能给它单独设当前壁纸、轮播路径、显示方式与过渡；轮播到点时每块屏各换一张。显示器拔掉后它的设置会保留，接回来自动恢复，用不上了可以在布局图下方「忘记」。
- macOS 原生模式支持多显示器逐屏独立：每块显示器各设当前壁纸、轮播路径与显示方式，轮播到点时各换一张；新接上的显示器自动换成它该显示的壁纸。窗口模式与原生模式互切时「逐屏独立」会保留。
- macOS 原生模式的壁纸显示方式新增「适应」「拉伸」「居中」（原来只有填充，铺法由系统决定），改了立即生效，每块显示器可以不同。
- 多块显示器逐屏独立时，图库「设为壁纸」、画册「设为桌面轮播」、查询行「用当前视图轮播壁纸」会先让你选显示器（默认选中默认显示器，双击即可），成功提示带显示器名；画册只在部分显示器上轮播时仍可设给另一块。托盘「下一张壁纸」只切鼠标所在的那块显示器。
- Wallpaper Engine 壁纸可以从另一台电脑复制过来（例如把 Windows 上的壁纸传到 macOS）：源电脑开启「设置 → 高级」里的 Web 服务器，这台电脑用「Kabegame 服务器」插件（0.3.0）收集。整个壁纸目录逐个文件下载到下载目录，一张壁纸一个文件夹，标签与创意工坊地址一并带过来，任务日志逐文件显示进度；本机已有内容相同的壁纸时不会多存一份（需开启「自动去重」）。两台电脑的 Kabegame 都需要 4.7.0 或更高版本。从图库删除这类壁纸只删记录，下载目录里的壁纸文件夹不会被删除。
- 本地导入（含把文件夹拖进主窗口或画册）现在能识别 Wallpaper Engine 壁纸目录：选中的文件夹本身或它下面某一层是壁纸目录时，整个目录作为一张壁纸导入，不再把里面的预览图和视频拆成一张张图片。拖进文件夹画册时整个壁纸目录会原样复制进同步目录。
- 文件夹画册同步目录里的 Wallpaper Engine 壁纸目录，现在作为一张壁纸出现在这个画册里，不再为它另建子画册；整个目录删掉后，对应的壁纸也从图库移除。旧版本已经为它建了子画册的目录保持原样；已经同步过的文件夹里原有的壁纸目录，要等这个文件夹下次有变化时才会被识别。
- 收集任务新增「失败重试」：在收集弹窗、网页收集与运行配置里打开开关并填 1–10 次，任务运行中失败后会立即用相同参数重新发起，取消不会重试。重试出来的任务带「重试 k/n」标记，点开可查看整条重试记录（从新到旧，已删除的任务显示占位），运行参数里能跳到原始任务。
- 「壁纸」收集现在也会导入 Wallpaper Engine 场景壁纸（含创意工坊打包的 `scene.pkg`）。少数简单场景（如自带的 eagleflag、deep_space、beach）已能在图库预览和桌面实时渲染，属性面板改颜色等即时生效；其余场景显示作者预览图，渲染能力会逐步加入。
- 场景壁纸支持图层效果链与颜色混合模式，自带的 Razer Vortex 现在可实时渲染；设置页壁纸分区新增「场景后处理」（跟随 WPE / 关闭 / 开启 / 超高，默认跟随 Wallpaper Engine 自己的后处理设置）。
- 场景壁纸支持泛光与 HDR：「场景后处理」为开启或超高时，开着泛光的场景按 Wallpaper Engine 的算法画出光晕（超高档另有 HDR 高光与更柔和的多级光晕），光晕本身与 Wallpaper Engine 的输出逐像素一致（相差不超过 1/255）；图库预览、应用背景与桌面同一档位，超高档 4K 场景多占约 90 MB 显存。Razer Bedroom 在「场景后处理」为开启或超高时可见光晕。
- 场景壁纸支持 Wallpaper Engine 场景脚本（SceneScript）的基础部分：Razer Bedroom 现在可实时渲染彩虹灯带，Razer Vortex 的「模式」属性生效；一段脚本的某个回调出错只停用该回调，其余照常运行；场景脚本的存储（如记住的拖动位置）会保留到下次打开。脚本读到的位置、颜色、角度等数值和 Wallpaper Engine 一样是单精度，逐帧累加的脚本与 Wallpaper Engine 的结果逐位相同。
- 场景壁纸支持图层层级与第一批粒子效果：子图层跟随父图层移动、旋转与显隐；粒子的发射、运动、淡出、振荡与透视粒子按 Wallpaper Engine 的方式模拟，并逐帧对照过 Wallpaper Engine 的输出。自带的 Shimmering Particles 与创意工坊 3062029089 现在可实时渲染；改粒子数量、发光、风格等属性即时生效，不重新加载。
- 场景壁纸支持更多粒子效果与纹理格式：R8 / RG88 / DXT1 / DXT3 纹理；粒子序列帧动画（含随机帧与混帧）；按时长、延迟或周期发射，盒形发射区；粒子的尺寸、透明度、颜色随寿命变化，尺寸振荡、旋涡、限速、湍流与随机偏移；折射与裁切粒子；粒子的颜色覆盖（改颜色属性即时生效，不重新加载）。这些都逐帧或逐像素对照过 Wallpaper Engine 的输出。创意工坊 2854083091、3799426930、3812822229、3829603837、1504316159、3820104696 现在可实时渲染；用植物摇摆效果的场景（如创意工坊 2418800402）摇摆速度和 Wallpaper Engine 一致。
- 场景壁纸的粒子支持跟随鼠标、吸引与排斥、拖尾与朝向：粒子可以跟着鼠标出生（图库预览与桌面都生效，填充、适应、居中等壁纸样式下都落在光标下的画面上），可以被场景里的某个点吸引或推开；挂在会动的图层上的粒子可以留在原地、不跟着图层跑；拖尾粒子按速度拉长；粒子的朝向（面向镜头、直立、固定方向）与 Wallpaper Engine 一致，挂在倾斜图层上的粒子也照样面向镜头。这些都逐帧或逐个角点对照过 Wallpaper Engine 的输出。创意工坊 1838478131、3832772446 现在可实时渲染。
- 场景壁纸的粒子支持绳状拖尾与更多运动效果：用「绳」连起来的粒子与粒子身后的轨迹拖尾、绕点环形或两点之间排布、按时间与噪声改变大小 / 透明度 / 速度、保持与某点的距离、靠近某点减速与涡旋，都按 Wallpaper Engine 的方式模拟和绘制，并逐帧对照过它的输出（绳的形状与贴图坐标逐顶点一致）。鼠标拖尾这类用绳画的场景（如创意工坊 2254685070）现在能实时渲染。
- 场景壁纸的粒子支持子系统与音频响应：粒子可以带自己的子粒子系统，跟着父粒子一起动、在父粒子出生或消失时迸出（如萤火虫周围的火星、闪电落下时的光晕），子系统的个数上限、出现概率与位置都按 Wallpaper Engine 的规则，并逐帧对照过它的输出；声明了支持音频的场景里，粒子的发射量与扰动会随正在播放的声音变化（Windows），频谱的处理与 Wallpaper Engine 相同，没有声音时这些粒子不发射，和 Wallpaper Engine 一致。创意工坊 3778592720、3811798465、1514925620 现在能实时渲染。
- 场景壁纸的粒子支持脚本控制：场景脚本可以暂停、停止、重新播放粒子，或手动补发粒子，粒子的数量、大小、速度、透明度、颜色与控制点也能由脚本或属性在运行中改（如随音乐变化的粒子数量与大小），时机与 Wallpaper Engine 相同；HDR 场景里粒子的亮度设置生效；一个粒子系统同时带普通粒子与拖尾时两者都会画出来。三处 Wallpaper Engine 的异常行为没有照搬：粒子自然停止后脚本重新播放会再次发射，脚本停止后改参数不会自行恢复发射，脚本补发时迸出的子粒子落在正确的位置。
- 场景壁纸支持声音：场景里的背景音乐与音效会播放，循环、单次、随机间隔三种播放方式，多首随机连播，以及作者设的音量（含音量属性），都按实测 Wallpaper Engine 得出的规则实现；场景脚本可以播放、暂停、停止声音和调音量。音量跟随设置里的「壁纸音量」，应用背景与暂停时不出声。创意工坊 1967162875、3827677885 现在可实时渲染。
- 场景壁纸支持视差、镜头抖动与缩放：开了视差的场景里，各图层随鼠标移动前后错开，形成景深感，移动的幅度、方向和跟随快慢都按作者的设置；镜头抖动与画面缩放也按作者的设定播放，属性和脚本改这些设置时即时生效。测试场景和 Wallpaper Engine 的输出逐像素一致。图库预览与桌面一打开，图层和跟随鼠标的粒子就按当前光标位置摆好，不用先动一下鼠标；应用背景不跟鼠标。另按 Wallpaper Engine 修正了几处判定（材质文件里的注释、透明图层的深度设置、编辑器留下的裁剪偏移等），不再把场景误判为不支持。创意工坊 3778549173、2272499163、2279259068、2381978484、2382002554、2382120706、2382121137、2570822804、2955749185、3000769374、3445915391、3818481122、3830255100 现在可实时渲染。
- 场景壁纸支持组合层、全屏图层与纯色图层：组合层（含可调整组合层、全屏组合层、项目组合层）取下层画面再叠加效果，带子图层的组合层把子图层画在自己的区域里、超出部分裁掉；全屏图层铺满整个画面；编辑器建的纯色图层按作者的颜色、贴图与效果显示；带 3D 旋转并开了透视的图层按透视显示；图片的边缘与自动尺寸也按 Wallpaper Engine 的规则处理。测试场景和 Wallpaper Engine 的输出逐像素一致（相差不超过 2/255）。创意工坊 1923929928、1333579536 现在可实时渲染；用到这些图层的其它场景大多还缺文本、木偶动画、视频等别的能力。
- 场景壁纸支持静态 3D 模型（正交视角的场景）：模型文件的各个版本、模型的多套材质（皮肤）、多个网格的前后顺序、背面剔除与画面外的模型不画，都按实测 Wallpaper Engine 得出的规则实现，测试场景和 Wallpaper Engine 的输出逐像素一致。Wallpaper Engine 自带的 Retro 现在可实时渲染；其余带模型的场景大多是透视视角，或还缺反射、音频频谱等别的能力，暂时仍显示预览图。
- 场景壁纸能编译创意工坊作者手写的全部着色器：Wallpaper Engine 能接受、以前被判为不支持的写法（向量宽度不一致的赋值与运算、数字当条件、多出来的 `#endif`、同名宏重复定义等）现在按 Wallpaper Engine 的规则编译，本机全部场景用到的着色器都能编译通过，画面与 Wallpaper Engine 逐像素一致（相差不超过 2/255）。创意工坊 3822495444、3831518461、3837598414 现在可实时渲染；其余用到这些效果的场景大多还缺视频、关键帧动画、音频频谱等别的能力。
- 场景壁纸支持 Wallpaper Engine 自带的流体模拟效果，以及效果里按选项开关的步骤与贴图：按 Wallpaper Engine 的规则处理，流体逐帧对照过它的输出。按图层缩放修正形状的创意工坊效果（如圆角遮罩）现在能用，画面与 Wallpaper Engine 逐像素一致。着色器里声明了却没用到的参数，不再让场景被误判为不支持。用到这些效果的场景大多还缺文本、音频、视频等别的能力，暂时仍显示预览图。
- 场景壁纸能画用到大量插值变量的创意工坊效果（如摆动效果 auto_sway、音频示波器）：这些变量按 Wallpaper Engine 的方式排布，不再因为超出显卡的接口数量上限而整张退回预览图，画面与 Wallpaper Engine 对照过。创意工坊 3585875739（音频示波器）现在可实时渲染；用到摆动效果的场景还缺别的能力，暂时仍显示预览图。效果里边缘宽度为 0 的平滑过渡（如示波器没有声音时的线条、VHS 干扰带宽度或摆动羽化调到 0）按 Wallpaper Engine 的结果计算，不再整张变亮或反相。
- 场景壁纸支持视频：作为图层画面的视频（包括创意工坊打包在场景里的 4K 视频与 HEVC 视频）会循环播放，被隐藏的视频图层自动暂停解码，暂停壁纸时一起停；和 Wallpaper Engine 一样不出声。画面与 Wallpaper Engine 对照过，只在颜色剧烈变化的边缘有细微差别。创意工坊 3822149301、3824550659、3828359750 现在可实时渲染；其余带视频的场景大多还缺文本、音频频谱、关键帧动画等别的能力。HEVC 视频需要显卡支持硬件解码，不支持时这个图层显示为透明。
- 场景壁纸支持音频频谱：声明了音频处理的场景里，读系统声音频谱的效果（频谱条、随音乐跳动的光圈等）会跟着正在播放的声音动，和 Wallpaper Engine 用的是同一份数据，测试场景逐帧逐像素一致。创意工坊 3502090109、3585875739、3825170583 现在可实时渲染；其余用到音频频谱的场景大多还缺文本、关键帧动画、媒体信息等别的能力。只在 Windows 上有声音数据，其它系统上频谱保持为 0。
- 场景壁纸支持作者开放的自定义图片属性：在属性面板里给这类属性选一张图片、GIF 或 MP4 视频，场景里对应的图层或效果贴图就换成它，按 Wallpaper Engine 的规则从正中裁成需要的比例，改了立即生效、不重新加载场景；清空后回到作者的贴图。图片的解码、GIF 的合成与播放节奏都逐像素对照过 Wallpaper Engine 的输出，只有 JPEG 的颜色边缘和标清视频的色彩有细微差别。创意工坊 3462279189、3783690410 现在可实时渲染；系统媒体封面、快捷方式图标这两类贴图来源还没实现，用到它们的场景仍显示预览图。
- 场景壁纸支持形状光束、图层对齐、图层互相引用与透明写入设置：编辑器里的光束形状图层按 Wallpaper Engine 的规则画出；图片图层的对齐方式（如左上、底部居中）生效，子图层不受影响，场景脚本也能读写；遮罩、混合类效果可以引用别的图层（包括隐藏的图层）的画面；图层叠加效果时的边缘处理、像素风图层的不插值、材质的透明通道写入与「透明度覆盖」混合也按 Wallpaper Engine 的规则处理（以前个别图层叠加效果时边缘会露出另一侧的画面）。测试场景逐像素对照过 Wallpaper Engine 的输出，只在纹理缩小处有细微差别。创意工坊 3656079027、3668499717、3811764016、3812887609、3819646765、3821678218 现在可实时渲染；其余用到这些功能的场景大多还缺场景脚本、关键帧动画、木偶动画等别的能力。
- 场景壁纸支持关键帧动画：编辑器里给位置、旋转、缩放、颜色、透明度、效果参数、缩放镜头等属性打的关键帧会按 Wallpaper Engine 的规则播放（循环、往返、只播一次，子动画跟随父动画），改属性时动画接着走、不从头开始；动画值逐帧对照过 Wallpaper Engine 的输出。创意工坊 2251857160 现在可实时渲染。脚本也能控制动画（播放、暂停、停止、跳帧、调速）并收到动画事件，规则对照过 Wallpaper Engine；用到它们的创意工坊场景多数还要等光标与媒体交互，暂时仍显示预览图。
- 场景壁纸支持透视 3D 场景、相机对象、深度与透明排序：用透视相机的场景（相机路径、相机抖动）按屏幕分辨率实时渲染，对象之间的遮挡（深度测试、背面剔除）和半透明物体由远到近的绘制顺序都按 Wallpaper Engine 的规则处理；场景里的相机对象（含脚本移动相机、按属性切换多个相机、缩放镜头）能控制视角，粒子也会面向相机。测试场景逐像素对照过 Wallpaper Engine 的输出，几张真实壁纸的相机与矩阵也逐项对过，只在纹理缩小处有细微差别。创意工坊 dna_fragment、techno、neon_sunset 现在可实时渲染；其余带相机对象的场景还缺文本、骨骼动画等别的能力，暂时仍显示预览图。
- 设置页壁纸分区新增「场景反射」（跟随 WPE / 关闭 / 开启，默认跟随 Wallpaper Engine 自己的反射设置）。反射关着时，地面倒影这类读反射的 3D 场景按 Wallpaper Engine 的方式显示（倒影处是背景色），Wallpaper Engine 自带的 Arsenal、Audiophile、Fantastic Car 现在可实时渲染，逐帧对照过它的输出；反射开着的画面还没实现，这时这些场景显示预览图。
- 场景壁纸支持木偶（puppet）骨骼动画：编辑器里做的木偶图层按 Wallpaper Engine 的规则播放骨骼动画，多个动画层的循环 / 往返 / 单次播放、覆盖 / 按权重 / 叠加三种混合与淡入淡出都按实测实现；动画层的速度、显隐等属性改了立即生效、不重新加载；带效果的木偶图层先做完效果再贴到木偶网格上。骨骼矩阵逐帧对照过 Wallpaper Engine 的输出（多数逐位相同），测试场景与两张真实壁纸逐像素一致。创意工坊 2896608544、3203778110、3351072238、3354366708、3409595232、3811769317、3813473025、3814576310、3818986268、3828324728 现在可实时渲染；木偶的挂点、变形、骨骼透明度、裁切遮罩、脚本控制与骨骼物理还没实现，用到它们的场景仍显示预览图。
- 新增应用日志：运行日志分级并按天保存到数据目录下的 `logs` 文件夹（保留 14 天），工具箱新增「查看日志」，可按级别、前端 / 后端、模块和关键字筛选，实时滚动，支持复制与打开日志目录。Web 版仅 super 模式可用。
- 网页壁纸可在预览详情栏与设置页调整作者提供的属性，桌面壁纸实时生效；支持文件与目录属性。
- 场景壁纸现在跟随壁纸样式（填充、适应、拉伸、居中、平铺），适应和居中时空白处用壁纸的主题色填充，和 Wallpaper Engine 一样；图库预览里场景壁纸按自身比例完整显示，和单独的图片一样；详情面板显示场景分辨率，宽高比筛选与排序也包含场景壁纸。
- 网页与场景壁纸可在预览的右键菜单或底部工具条把当前画面设为壁纸封面，替换作者的低清预览图，也可在预览详情栏恢复默认封面。
- 网页与场景壁纸可在预览的右键菜单或底部工具条暂停（排在第一个，画面出来后可用）；场景壁纸还可清空脚本存储。「设为壁纸」的图标换成了显示器。预览网页与场景壁纸时，直接在壁纸画面上右键也能弹出菜单。
- 壁纸设置新增「暂停壁纸」：窗口模式下暂停桌面上的视频、网页与场景壁纸，换壁纸后仍保持暂停；暂停期间桌面上的鼠标移动与点击不再转发给网页和场景壁纸。原来在「壁纸属性」弹窗里的暂停开关与清空脚本存储移除。
- Windows 上的 Wallpaper Engine 网页壁纸支持音频可视化与媒体集成：声明了音频处理的壁纸会随系统正在播放的声音跳动；壁纸可显示正在播放的歌曲名、歌手、封面、播放状态与进度（来自系统媒体控制，网易云、Spotify、浏览器等均可）。桌面与图库预览都生效。设置页壁纸分区新增「网页壁纸媒体集成」开关（默认开启），关闭后壁纸读不到歌曲信息。
- 预览视频或网页壁纸时，系统媒体浮窗显示图片名称与 Kabegame 图标，不再显示「画廊」。
- 新增「壁纸」收集入口：自动发现本机 Wallpaper Engine 壁纸（Steam 创意工坊订阅、官方默认、我的项目），也可手动添加壁纸目录；第一阶段把 `video` 型壁纸原地引用入库，使用作者自带的 `preview.gif` / `preview.jpg` 作为图库预览，不复制、不转码用户目录。
- 壁纸设置新增「Wallpaper Engine 目录」：留空时自动查找（Steam 库，或从已导入的壁纸往上找）并写入，也可以手动指定。没有 Steam 版 WPE 时，把 `assets` 等资源复制到本机就能让场景壁纸读到内置资源，做法见文档「Wallpaper Engine 壁纸」。
- Wallpaper Engine 壁纸现在也支持 macOS 和 Linux：可以导入并在图库预览、应用背景里运行网页与场景壁纸，macOS 还可在窗口模式设为桌面壁纸；音频可视化、媒体集成和桌面鼠标转发仍只在 Windows，Linux 暂不能设为桌面壁纸。Android 与 Web 版不提供。
- 「壁纸」导入现在会带上 Wallpaper Engine 里显示的全部标签：除作者声明的题材外，还有音频响应、可自定义的、视频纹理、年龄分级等（不含分辨率），并按题材、年龄分级、特性分到 `WPE` 下的子目录，名称跟随导入时的界面语言。
- 「壁纸」导入支持 Wallpaper Engine 网页壁纸：原地引用壁纸目录；预览以主屏比例的画布运行页面并可交互，也可在窗口模式设为桌面壁纸，应用背景同样实时显示（静音）。设置里的「壁纸音量」（原「视频壁纸音量」）对网页壁纸同样生效。
- 桌面网页壁纸改为像 Wallpaper Engine 一样以 `file://` 直接加载壁纸目录：依赖读取同目录数据文件的壁纸（如歌单、字幕类）现在能完整运行；文件访问只对壁纸窗口开启，且只能读当前壁纸目录内的文件。Windows 上桌面的鼠标移动与左键点击会转发给网页壁纸（不拦截桌面本身的点击，桌面框选不受影响）。预览网页壁纸时，鼠标移到画布左右边缘中段即可唤出切换箭头。预览网页壁纸时右键菜单无法弹出（右键会被壁纸页面接收），菜单里的操作改为按原顺序排在底部工具条里。
- 网页壁纸可读取作者默认属性与界面语言：桌面壁纸与图库预览里的 Wallpaper Engine 网页壁纸会在加载完成后收到 `project.json` 里作者设定的属性值，以及当前界面语言（切换语言后页面随之更新）；依赖这些属性才开始绘制的壁纸现在能正常显示。暂不支持帧率上限。
- 画廊、画册、任务和畅游的工具条右侧 ⋯ 菜单新增「收藏的视图」：把当前的过滤和排序存成一条，可以起名字（不起就用路径作名字，名字不能重复），以后点一下就切回去。列表按最近使用排序；在菜单里来回切换不会打乱顺序，下次打开菜单时才把最后用的那条排到最前。所有画册共用一份收藏，所有任务、所有网站也各共用一份。行尾的编辑按钮可以改名，或用当前视图更新这条收藏（先预览哪些条件是新增的、哪些会被移除，确定后才保存）；叉号移出收藏，需要确认。正在轮播的那条带轮播标记。收藏保存在本机。
- 设置页壁纸分区新增「显示器布局」（目前仅 macOS）：按系统里的排布画出接着的每块显示器及其名字、分辨率，插拔显示器、改排布后约一两秒内自动更新。壁纸设置的各项按「全局设置 → 显示器 → 轮播路径、当前壁纸、显示方式与过渡」重新排了顺序，「壁纸模式」移到了前面。
- 新增按颜色排序：画廊、画册、任务和畅游的排序菜单多了「颜色」，点开选一个色块（红橙黄绿青蓝紫粉棕黑白灰），画面最接近这个颜色的排在前面；也可以点「＋」自己取色，直接按它排序，或把常用的颜色保存下来（最多 24 个，保存后排序更快）。Wallpaper Engine 壁纸与视频同样参与。
- 图片详情的「基本信息」里新增代表色：一条按占比分段的色带，鼠标停在上面显示色值与百分比，点其中一段可以让当前页面按这个颜色排序（过滤条件不变）。升级后会在后台为已有图片计算一次代表色，期间可正常使用，还没算到的图片按颜色排序时暂时排在最后。
- 整理新增「重新计算代表色」：为整理范围内的每张图片重新计算代表色（换了文件、当初没算出来，或者想按新的算法更新时用），算不出来的保留原来的代表色；进度和完成提示里会显示更新了多少张。

### Optimized
- 场景壁纸改颜色、透明度、位置、亮度与滑块类属性时即时生效，不再整场重新加载；按属性条件显示 / 隐藏的图层也能正确切换。
- 场景壁纸开关图层效果、泛光，以及改背景色等属性时也即时生效，不再重新加载。
- 场景壁纸图层的贴图采样位置与 Wallpaper Engine 对齐，放大低分辨率贴图时不再有亚像素偏移。
- 桌面版窗口标题随当前内容显示预览图片名、画册名及畅游 / 爬虫页面标题，并跟随界面语言切换；Web 版标签页标题同步采用「内容 - 页面 - Kabegame」格式。
- 窗口模式桌面壁纸（含 Windows 网页壁纸）卡死或与后台失联时，会在约 30~40 秒内自动重新加载，不再一直停在旧画面或白屏；壁纸被其它窗口遮住时不会误判。
- 桌面版（Windows / macOS / Linux）图库、预览与窗口壁纸里的图片、缩略图和视频改由内置浏览器直接读取本地文件，不再经过应用内的本地 HTTP 服务；桌面本地 HTTP 文件服务不再监听端口，复制兜底改用 `file://`。插件文档和配图由应用内命令读取并缓存。插件详情页（插件模板）改在更严格的隔离环境里运行：模板不能再直接发网络请求或访问主界面，模板里写的远程图片照常显示。
- Windows 桌面版从图库把图片或视频拖到资源管理器、Word、聊天软件等程序时，得到的是库内原文件（不再是缩略图或需要下载的地址）；三个桌面平台的拖出都只复制，不会把库内文件移走。
- Windows 安装程序在最后阶段不再一个接一个地闪出大量黑色命令行窗口：搬运 CEF 运行时、DLL 与设置目录图标属性改用安装程序内置指令完成。
- 桌面端界面卡死后的自动恢复更快：页面无响应约 6 秒（原约 16 秒）即自动重新加载。
- 按视频筛选和视频计数在大图库下明显更快；应用启动时会刷新数据库的查询统计，启动页显示「正在优化数据库」，图库越大这一步越久。

### Fixed
- 主窗口缩到很窄时，设置页「当前轮播路径」「当前壁纸」两行的标题不再被长路径挤成一列字。
- 修改壁纸轮播间隔后，从修改的那一刻起按新间隔切换，不用再多等一轮。
- 窗口模式与原生模式的显示方式、过渡各记各的：窗口 → 原生 → 窗口来回切换后，窗口模式原来的显示方式与过渡不再被原生模式的值覆盖（第一次切到另一个模式时仍沿用当前的值）。
- 设视频或 Wallpaper Engine 壁纸时，在「需要切换到窗口模式」的确认框里点取消，不再弹出「壁纸设置失败: cancel」。
- 把当前壁纸那张图隐藏、移出画册，或它被当前的过滤条件排除时，应用背景不再消失（只有删除这张图才会清掉）。
- 原生壁纸模式下从图库设一张壁纸，不再把「过渡效果」改回「跟随系统」；Windows 原生模式下轮播切换时系统壁纸只更换一次，不再连续刷新；还没有设过壁纸时修改显示方式，不再直接改动系统当前的壁纸，下次设壁纸时才生效。
- 同时开着「自动去重」和「去重时更新元数据」时，下载到与某张 Wallpaper Engine 视频壁纸的视频内容相同的文件，不再把这张壁纸的来源和详情改成下载插件的（改了之后壁纸属性面板与详情会失效）；现在只补画册、标签并计入去重。
- 场景壁纸的材质参数按 Wallpaper Engine 的规则取值：单个数字填满颜色 / 向量的每个分量，用逗号分隔的数值也能读到，类型不对的值（如给数值参数写了文字或开关）不再被硬塞进去，运行中改属性也不会残留旧分量；两个着色器阶段共用的同名参数取片元着色器的默认值。目前能渲染的场景画面不变，模糊、滚动等以后开放的效果不会再缺一个方向。
- 在图库预览的网页或场景壁纸上按住 Ctrl 滚动滚轮，不再把整个应用一起放大缩小；以前这样缩放过的，下次打开时自动恢复原大小。
- 图库预览场景壁纸时，画面不再多出主题色留边、整体缩小，也不再按远大于显示的尺寸渲染。
- 场景壁纸的开关类设置（如相机视差）关联到滑块等非开关属性时，按作者在场景里写的开关值生效，和 Wallpaper Engine 相同；以前会被当成关闭。相机视差跟随鼠标的平滑过程与 Wallpaper Engine 逐像素一致。场景里关联的属性在壁纸里不存在时，图层的显示 / 隐藏、数值与脚本参数也按作者写的值生效（以前创意工坊 3351072238 的背景视频会被藏起来）；图层透明度、亮度关联到开关或按条件显示的属性时同样保持作者的值；显示开关关联到数字或文字属性时也保持作者的值；Wallpaper Engine 自带的对齐、播放速度、颜色校正等属性，场景与脚本也能读到（对齐跟随壁纸样式）。
- 「壁纸」导入只添加文件夹、没有勾选自动来源时不再提示「壁纸导入任务创建失败」。
- 预览视频后切到其它图片或关闭预览，立即释放视频播放器：系统媒体浮窗不再停在已经切走的视频，也不再盖住桌面壁纸正在放的歌。
- 修复网页壁纸刚打开时偶尔要等几秒才应用属性、读不到为它选择的文件夹的问题。
- Windows 桌面版畅游在 x.com 等限制严格的网站上，下载视频等大块数据不再降级到慢速通道。
- Windows 窗口壁纸改挂到桌面背景 WorkerW，移除点击桌面和最小化时反复修正图标层 Z-order 的逻辑。
- Android 平板 / 横屏宽屏布局的侧栏、主内容区与弹窗不再被状态栏、底部导航栏遮挡；平板上的弹窗与桌面一样限高、只在内容区滚动，底部按钮始终可见。
- Android 平板（宽度超过紧凑断点）打开图片预览后左右滑动不再停在原图，能正常切换上一张 / 下一张；滑动过后按一次返回即可关闭预览，不再先被背后的多选状态吃掉。
- Android 吉祥物亀ちゃん不再被底部导航栏挡住脚部，拖动范围也限制在系统栏之内。
- Android 预览图片视频滑动后不暂停播放的问题
- WebView 爬虫打开的网站不再能订阅应用事件（此前可读到图库新增图片的本地路径等信息），也不能向主界面伪造事件。
- 修复下载时偶发「UNIQUE constraint failed: images.local_path」：同一帖子多张同名图片并发下载不再互相覆盖、丢图，会依次存成 `name.jpg`、`name(1).jpg`……；下载目录同时是文件夹画册时，新下载的图片也会立刻进入该画册，不再与文件夹同步抢着入库。
- Windows 桌面版畅游打开 https 网站时，地址同步、一键下载、右键下载图片和页面内提示等功能全部失效的问题。
- 畅游时（尤其开着开发者工具）右键图片不再叠出两个「下载图片」菜单、要点两次才关闭；页面加载时的地址上报等也不再重复发送。
- 桌面网页壁纸切换后有时不再跟随属性与界面语言变化、偶尔只显示「请选择目录」之类的空白提示的问题；同时堵住了网页壁纸在切换瞬间可能取得应用主界面权限的漏洞。
- 网页壁纸带步长的滑块属性，在输入框直接键入的数值也会对齐到步长（例如步长 0.25 时键入 1.3 得到 1.25），与拖动滑块一致。
- 安全加固：畅游导航栏、桌面网页壁纸等页面只能监听为它们开放的应用事件，发给某个窗口的事件不会再被其它窗口收到；页面里嵌入的子页面（iframe）不再沿用所在页面的应用权限。

### Changed
- Wallpaper Engine 壁纸的「大小」改为整个壁纸目录的总大小（原来只算入口文件），按大小筛选和排序随之变化；判断两张壁纸是否相同也改为比较整个目录的内容。升级后会在后台为已有的壁纸重新计算一次，「我正在忙这些」里能看到进度；算完之前，下载到本机已有的壁纸可能多存一份。

## 插件开发侧

### Changed
- kabegame-server（0.3.0）：`x-wpe/*` 行改为先请求 `/file/<目录>` 取文件清单，再经 SDK 的 `downloadWpeWallpaper` 整目录复制；`engines.kabegame` 提到 `>=4.7.0`。
- 图片详情的插件模板（`description.ejs`）iframe 不再与应用同源（去掉 `allow-same-origin`），并在文档最前带内层 CSP（`connect-src 'none'`、`frame-src about:` 等）：模板里直接 `fetch` / XHR / WebSocket、`<link>` 外链样式、远程字体、嵌套 http(s) 或 `file:` iframe 都会被拒，网络请求一律经 `__bridge.fetch`；`<img>`、CSS 背景等元素级远程图片与嵌套 `srcdoc` iframe 不受影响；`window.parent`、`localStorage` 不可访问（跨次缓存用 `__bridge.getCache` / `setCache`）。

### Added
- `Kabegame.downloadImage(vfsPath, { relocate: true })`（V8 与 WebView）：`url` 是 `Kabegame.fs` 的虚拟路径时，把这个文件或目录移进输出目录而不是复制一份，库里已有相同内容时直接删除，调用之后该路径不再存在；只对虚拟路径生效。源必须在可写挂载上，不能是挂载根，也不能包含符号链接。虚拟路径可以是一个 Wallpaper Engine 壁纸目录（必须带 `relocate: true`，仅桌面端），整个目录作为一张壁纸入库，metadata 固定是它自己的 `project.json`（`metadata` / `metadata_id` 被忽略）。`@kabegame/types` 同步新增 `KabegameDownloadImageOptions.relocate`。
- `@kabegame/plugin-sdk` 新增 `downloadWpeWallpaper`（`@kabegame/plugin-sdk/wpe`）：按文件清单把壁纸目录逐个文件 `fetchToFile` 到任务 VFS 的 `tmp/wpe`，再整目录提交；支持单文件重试、大小校验、逐文件回调与空跑，并清理 12 小时以上的残留。
- 桌面端 Web 服务器的 `/file/<目录路径>` 对 Wallpaper Engine 壁纸返回文件清单 `{ type, files: [{ path, size }] }`，`/file/<目录路径>/<相对路径>` 返回目录里的文件（越出目录的路径 404）。
- `kabegame-cli plugin run` 新增 `--freeze-template`：把本次运行插件的 `description.ejs` 冻结进每行 metadata（新列 `metadata.template`），详情面板优先用它渲染。`--id` 测试 id 没有安装，过去它下载的图片只能看原始键值，现在也能直接在应用里调试模板。插件模板与冻结模板并行获取，冻结模板非空时覆盖插件模板。

### Fixed
- `kabegame-cli plugin new` 模板的 rspack 输出路径改用 `fileURLToPath`：原来的 `URL.pathname` 在 Windows 上是 `/D:/...` 形式，rspack 产物落不到插件的 `dist/`，打包时报 `main 脚本不存在`（模板编译期内嵌，重新构建 CLI 后生效）。
