# v4.3.0 changelog

## Added
- **爬虫**: webview 爬虫插件现在可以多窗口了
- **畅游**: 畅游现在不受限制可以多窗口了
- **插件**: v8插件就绪，可以以编写vscode插件一样的体验来编写kabegame插件啦，并且运行速度快得飞起（教程文档编写中）
- **过滤器**：画册、畅游、任务页面都可以用画廊全套组合过滤器啦，これは全部PathQLの最強たる拡張性のおかげだよ、やった〜

## Fixed
- **动态库**: windows、macos和linux现在带上依赖的动态库和搜索路径，尽量能够在更多系统上能够运行。
  - ffmpeg 依赖
  - cef 依赖
- **预览**: 手机屏幕预览抵达页的边界的时候自动翻页
- **i18n**: 首次语言设置从后端直达，非前端探测
- **整理**：修复整理不生成视频thumb、comp的bug
- **安卓**:
  - 安卓photoswipe滑动过快导致重复图片显示bug（最头疼！还好fable帮我揪出来根因了）
  - 快速滑动导致秒切下下张图片；
  - 失败图片弹窗无法显示的bug

## Optimized
- **任务**: JS任务在log旁添加了一个快捷打开webview的按钮
- **畅游**: 畅游下载视频更加健壮，用MSE、HSL hook来下载流式视频，**长视频暂不稳定，建议5分钟短视频，并且强烈建议在浏览器自然播放视频完毕一遍再右键下载视频**。
- **畅游**: 畅游下载内容会保留下载所在的页面url,非图片url；图片会保留所在页面的名称。
- **缩略图丢失**: 当缩略图丢失的时候，右上角出现黄色警告提示用户应该重新运行整理来生成。
- **插件**: 插件预打包，每个版本预打包所有插件，无需麻烦地每次都去github下载，但需要翻墙的插件仍然需要开梯子。
- **图片**：右键图片路径可以复制路径.
- **图片**: 图片url为blob、data的时候会被忽略；插件新版本会在下载时带来图片所在帖子而非最终url从而快速打开图片所在帖子。
- **安卓**：安卓photoswipe支持视频；图片列表变化导致图片不变安卓视频从kotlin压缩改成跨编的ffmpeg压缩，速度快20倍，几秒钟一个视频！

## Changed
- **界面**: webview现在用自研CEF运行时，Linux 上被 WebkitGTK 折磨的时代已经过去啦（代价是安装包膨胀100MB左右），并且还可以定制运行时和一致化webview行为。
- **VD**: Dokan依赖、fuse依赖不再硬要求，在用户打开虚拟盘的时候要求先安装该依赖
- **CLI**: 改为无需主程序/daemon 的自包含工具，移除 `plugin run`、`vd`、`ipc-status`，新增 `data import-image/query`；`--album /父/子` 通过 `albums://by_sub_tree` 解析现有画册。

## Removed
- **Light**: 自研 CEF 运行时使得 light 模式含义变为不包含 webview，但那样会影响程序行为并添加说明负担，因此去掉light模式。
- **CLI Bundling**: Standard 模式不再带kabegame-cli，cli改为单独发布。
- **毛玻璃**：由于CEF限制，毛玻璃侧边栏特效去掉，win11保留标题栏毛玻璃特效。
- **Rhai**: Rhai 插件后端被移除。仅剩v8和webview后端
